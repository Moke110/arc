# Stage 1 MIRI drug screen

The Stage 1 root retains the former v2 screen under ADR 0105. XPert finetunes
on the DToxS primary and iPSC union, and the screen scores 1,004 FDA drugs
against the MIRI reference. The formal run retained 130 drugs after the WCS
filter and 64 after the critical-pathway filter. See the
[cutover verification](verification.md) for parity with the original results.

## Materialize the inputs

Use the repository's conda environment, named arc. The workflow also needs
the original ignored input assets, the provenance-managed data sources, and the
XPert metadata in its declared local additions. Keep the external weight archive
mounted at its recorded target. The checksums in
[pre_cutover.sha256](pre_cutover.sha256) identify the original formal products.

When promoting the materialized v2 checkout, transfer its ignored payloads into
the new Stage 1 root before retiring the versioned directories. From the checkout
root, after the tracked tree is installed:

~~~bash
rsync -a --ignore-existing --exclude='__pycache__/' --exclude='.ipynb_checkpoints/' \
  stage1/xpert-fda-miri-v2/ stage1/
install -d stage1/input/references pert_data/Annotation/local
cp -p stage1/xpert-fda-miri-v1/03_cm_finetune_data/output/dtoxs.h5ad \
  stage1/input/references/
cp -p stage1/xpert-fda-miri-v1.1/03_cm_finetune_data/output/dtoxs_lincs.h5ad \
  stage1/input/references/
cp -p stage1/xpert-fda-miri-v3/03_cm_finetune_data/output/compound_external_audit.csv \
  pert_data/Annotation/local/
(cd stage1/input/references && sha256sum -c manifest.sha256)
bash pert_data/Annotation/script/verify_audit_seed.sh
~~~

The two predecessor H5ADs supply the original schema and official folds. The
Annotation CSV supplies the original offline public-registry seed. These inputs
are local data, so retain them with the materialized checkout or transfer them
from a verified copy when setting up a new checkout.
Annotation's `script/verify.sh` checks the downloaded HGNC source. The separate
`script/verify_audit_seed.sh` checks the installed local CSV.

The [checkpoint inventory](pre_cutover_weights.tsv) records workflow-relative
paths and symlink targets for the 52 frozen XPert weights. Preserve the links
themselves during materialization. After the retired siblings are unavailable,
run the following from the checkout root:

~~~bash
bash script/tests/stage1_path_constants.test
bash pert_data/Annotation/script/verify.sh
(cd stage1 && sha256sum -c pre_cutover.sha256)
~~~

The figures and tabular outputs generated by a rerun can vary with the
software and GPU environment. Run reproductions in an isolated worktree with
writable copies of outputs and the original products available for comparison.

Step 08 uses the original v2 GSE108940 landmark list pinned in
[input/references](input/references/). The shared disease-data version was
corrected after the v2 screen in commit 7d1d0dcc. Its addition of TP53 would
change the screen's reference and downstream scores. The historical pin also
retains the original metadata, including the species mislabel documented in the
[provenance correction](../docs/research/stage2-stage3-gene-axis-gse108940-provenance.md).

## Reproduce the screen

Run the [screen notebook](screen.ipynb) from Stage 1, or invoke the scripts
below in order. The notebook documents each input and output. For exact
comparison of newly generated outputs with the formal products, record the
Python, NumPy, PyTorch, CUDA and plotting library versions.

| Step | Entry point from Stage 1 | Formal products |
|---|---|---|
| 01 | `python 01_drug_embed/drug_list.py` and `python 01_drug_embed/drug_embeddings.py` | Drug list and author HG embeddings in `01_drug_embed/output/`. |
| 02 | `python _lib/verify_genes.py` and `python 02_cm_baseline/cm_baseline.py` | Verified landmark maps and consensus control expression. |
| 03 | `python 03_cm_finetune_data/build_union.py`, `python 03_cm_finetune_data/schema_gate.py`, and `python 03_cm_finetune_data/finetune_report.py` | Union H5AD, manifest, dataset summaries, reference quantiles, schema gate and composition report. |
| 04 | Use the author checkpoint and pretrain config under `04_xpert_pretrain/`. | Frozen L1000 XPert checkpoint. |
| 05 | `python 05_xpert_finetune_bench/full/create_cm_splits.py`, followed by `python 05_xpert_finetune_bench/full/xpert_finetune_bench.py`. Run `python 05_xpert_finetune_bench/data-ablation/xpert_data_ablation.py --dry-run` for mask gates and without the flag for scores. Run `python 05_xpert_finetune_bench/warmstart_pr/run_pr.py` for profiles and PR metrics. | Twenty folds, zero-shot anchors, ablation tables and figures, and direction-aware PR reports. |
| 06 | `python 06_xpert_finetune/xpert_finetune.py` | Final all-train checkpoint and training receipt. |
| 07 | `python 07_xpert_predict/perturb_transcriptome.py` and `python 07_xpert_predict/zscore.py` | Predicted landmark effect and per-gene z-scores. |
| 08 | `python 08_miri_phenotype/miri_phenotype.py` | Integrated phenotype gene sets and rank reference. |
| 09–11 | Run `09_miri_efficacy_scores/miri_efficacy_scores.py`, `10_filter/filter.py`, and `11_integrate/integrate.py`. | Scores, filters, final rankings, report and figures. |
| 12–13 | Run `12_drug_survey/assemble_reports.py`, `12_drug_survey/subset_reports.py`, and `13_limits/limits.py`. | Evidence-synthesis HTML from frozen dossiers and limitations figures and report. |

# tenv Denoise-DEG 5k training

This plate-pooled tenv release uses the ordered 5,000-gene
[Denoise-DEG prediction axis](../../02_gene_axis/02.2_denoise-deg/README.md).
Its [manifest](output/manifest.json) pins the axis, raw counts, frozen folds
and each output. See the [tenv release contract](../03.1_tenv_hvg-deg-5k/README.md)
for the data files and the [six-axis builds](../README.md#six-tenv-training-axes)
for reproduction with `--family denoise-deg --size 5000`.

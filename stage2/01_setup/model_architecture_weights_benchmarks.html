怎样读这些数字

论文里的“R² = 0.9”并不等于“这个模型更好”。不同论文用的数据集、划分方式、基因数、指标定义都不同。 下面先统一几个概念，后面的表才不会误读。

R²（决定系数）

衡量预测值能解释真实值多少方差。1 是完美，0 相当于“只用平均值猜”，负数比平均值还差。 在扰动预测里，R² 很容易被“大多数基因没变化”抬高，所以论文通常同时报告 DEG（差异表达基因）上的 R²。

Pearson / Spearman 相关

Pearson 衡量线性相关，Spearman 衡量排序相关。它们只看“趋势像不像”，不看绝对数值是否接近； 因此一个模型可以相关性很高但 R² 很低。扰动论文常用 Δ 表达（log fold-change）的 Pearson。

MSE / RMSE

预测值与真实值的平均平方误差（RMSE 是其平方根）。越低越好，但单位依赖数据预处理， 不同论文的 MSE 基本不可比。

冷药物（cold drug）

训练时完全没见过这个化合物，预测时只给它的结构（SMILES）。这是本项目最关键的泛化场景。 “药物级 holdout”不一定是冷药物：如果预测时仍然用了该药处理过的细胞，那是转导式（transductive），不是冷启动。

阅读原则：先看“数据集 + 划分 + 基因空间 + 指标”，再看数值。跨论文的单个数字不能直接排名； 本报告只在同一模型、同一论文内部做对照。

基因数量是否已经固定？

要分两层看：代码层面，大多数模型把基因数作为可配置参数；权重层面，一旦加载现成 checkpoint，基因数就被第一层/最后一层的权重形状锁死。换句话说，代码可以改成 20,570，但现有权重不能。

结论：这些模型输入和输出使用同一套基因（自编码/重构式），没有“输入基因集 A、输出基因集 B”的设计。 当前公开权重分别锁在 978、977、2,000、5,000、5,087 个基因；没有任何现有权重覆盖 20,570。 换基因数 = 重新训练（至少重训基因相关的编码器/解码器），不是改一个配置就能推理。

四个容易混淆的点

① “基因数量”不等于“基因身份”

两个模型都写 5,000 个基因，并不代表它们用的是同一批 5,000 个基因。CPA checkpoint 里存了具体的 5,000 个 var_names；biolord 的 checkpoint 也存了 4,999 个基因名；PerturbNet 的 sci-Plex 资产带一份 5,087 行的 var_names.csv。数量相同但基因顺序不同，权重也不能直接套。

② 有些 checkpoint 不带“可移植的基因列表”

PRnet 依赖 AnnData 的 var 顺序；chemCPA 的 checkpoint 配置只记录 num_genes， 不记录基因名。换数据时必须复现原来的预处理、基因筛选和列顺序，否则即使数量对上，预测也会错位。

③ 潜空间模型只是“部分”与基因数无关

PerturbNet 的 cINN 在 10 维潜空间工作，看起来与基因数无关；但它的输入/输出仍要经过 cell VAE， 而 cell VAE 的基因维是固定的（978 / 5,087）。CMonge 的条件 OT 在 50 维 AE 潜空间工作，同样受 AE 的 data_dim 约束。潜空间维度固定 ≠ 基因数可以随便换。

④ 输入和输出是同一套基因

这 9 个模型都是“给基线表达，预测处理后表达（或 Δ 表达）”，输入基因集和输出基因集相同。 没有模型做“输入基因集 A → 输出基因集 B”的跨基因集映射；因此输出层大小永远等于输入基因数。

对 Stage 2 的直接含义：目标 20,570 基因意味着所有模型都要重训基因相关部分； 没有“加载现成权重、直接换 20,570 基因”的捷径。可复用的是与基因无关的药物编码器 （PRnet rFCFP、chemCPA RDKit、PerturbNet ChemicalVAE、Squidiff rFCFP、CMonge RDKit）， 以及 PerturbNet 的 10 维 cINN / CMonge 的 OT 映射这类潜空间模块。

两个容易混淆的“编码器”问题

PRnet 与 Squidiff 的 rFCFP 是同一套实现

不是“两个相似的方法”，而是同一段编码逻辑。Squidiff 的 Drug_dose_encoder 在代码注释里直接写了 “adopted from PRnet”，两边都调用同一个 RDKit 函数。

相同点

  • RDKit GetMorganFingerprintAsBitVect(mol, radius=2, useFeatures=True, nBits=1024)。
  • 输出 1024 位 0/1 指纹；“FCFP”来自 useFeatures=True，不是另一种指纹。
  • 剂量缩放相同：fingerprint × log10(dose + 1)。
  • 组合药处理相同：多个化合物的指纹逐位相加。
  • 指纹本身不学习、不随模型训练变化。

不同点（都在下游）

  • PRnet：1024 维（组合时为 comb_num × 1024）→ CombAdaptor MLP（128→64）→ 64 维扰动向量 c，再进入 VAE 的编码器/解码器。
  • Squidiff：1024 维药物-剂量向量直接与对照表达融合，经 drug adaptor 更新语义潜变量 z_sem′，再进入扩散模型。
  • 因此“药物表示”相同，但“怎么用这个表示”不同。

注意：“相同实现”不等于“任何情况下 bit 级完全相同”。RDKit 版本、SMILES 标准化/互变异构处理不同，都可能改变指纹位。 在同一 RDKit 环境和同一 SMILES 下，两者输出一致。

一张图看懂：RDKit、2D、Morgan、FCFP、rFCFP 的关系

RDKit（化学信息学工具箱）
└─ 2D 描述符（从二维分子图算出的数字）
   ├─ 整体描述符：分子量、LogP、TPSA、环数……      → chemCPA / CMonge
   └─ 指纹（fingerprint）
      └─ Morgan 圆形指纹（逐原子看邻域）
         ├─ ECFP：按原子类型（useFeatures=False）
         └─ FCFP：按功能类别（useFeatures=True）    → PRnet / Squidiff
            └─ rFCFP：FCFP × log10(dose + 1)       → PRnet / Squidiff

它们不是四个并列的东西，而是“工具箱 → 数据类别 → 算法 → 变体 → 项目叫法”的嵌套关系：

  • RDKit：一个开源化学信息学工具包，负责读 SMILES、算描述符、画分子。
  • 2D 描述符：只看原子的连接关系（二维图），不需要三维构象；它是一个“类别”，不是某一种指纹。
  • Morgan：一种“圆形指纹”算法。对每个原子，收集它 1 圈、2 圈……邻居的信息，再哈希成固定长度的位向量。它既可以做 ECFP，也可以做 FCFP。
  • ECFP：Morgan + 原子类型（元素、电荷、度数等），记录“这个邻域里具体是什么原子”。
  • FCFP：Morgan + 功能类别（氢键供体/受体、芳香、卤素等），记录“这个邻域在化学上像什么”，不区分具体元素。RDKit 里就是 useFeatures=True。
  • rFCFP：不是标准化学术语，是 PRnet 的叫法，意思是“把 FCFP 的每一位乘以 log10(dose+1)”。它把“结构指纹”变成了“结构 × 剂量”的条件向量。

类比：分子像一座城市。2D 描述符是“城市统计”（面积、人口、道路数）；Morgan 是“从每栋楼出发，看 1–2 个街区内的店铺”；ECFP 记录“具体是咖啡馆还是药店”，FCFP 只记录“餐饮还是医疗”；rFCFP 再给这些记录乘上一个“剂量音量旋钮”。

chemCPA / CMonge 的分子表示 MLP 是怎么训练的？

先澄清一个常见误解：它们都不是先单独训练一个“分子 → 机制”的化学 MLP。 两者都是把一个小型 MLP 作为响应预测模型的一部分，端到端训练；MLP 的梯度来自“预测表达/分布是否准确”， 不是来自药物分类、靶点结合或通路标签。

下面讲的是公开 checkpoint 的 RDKit 分支：chemCPA 用的是 RDKit 2D 描述符（194 维）； CMonge 用的是 RDKit 2D 描述符（demo 过滤后 194 维）+ log 剂量。两者都不使用 3D 构象、靶点结构或结合亲和力数据。

chemCPA：药物 MLP 是 VAE 的一部分

训练数据：L1000 药物扰动表达谱（公开 checkpoint 为 977 或 2,000 基因、188 个药物）； 每个样本是“基线表达 + 药物 + 剂量（+ 协变量）→ 处理后表达”。论文的冷药物实验在 sci-Plex 单细胞数据上做。

输入表示：每个药物的 RDKit 2D 描述符先离线算好、删低方差列、z-score 标准化，存成 188 × 194 的冻结表；MLP 是 194 → 128 → … → 32，可训练。

损失函数：主损失是表达重构的 Gaussian NLL（同时预测每个基因的均值和方差）； 另有药物/协变量的对抗分类损失（BCE / 交叉熵）。对抗器作用在基础潜变量上， 目的是让基础细胞状态不包含药物身份；药物 MLP 本身的梯度主要来自重构项。

剂量：单独的 doser MLP 输入“原始 RDKit 描述符 + 剂量”，输出 0–1 的缩放系数， 乘到药物潜变量上；它和 AE 一起用重构损失训练。

CMonge：条件 MLP 是 OT 映射的一部分

训练数据：SciPlex3 单细胞数据（187 个药物、4 个剂量、3 个细胞系；论文 748 个药物-剂量条件）； 4i 数据（35 种治疗，分析用 27 个单药 + 6 个组合）。每组训练样本是“对照细胞分布 + 条件 → 处理细胞分布”。

输入表示：RDKit 2D 描述符在 SMILES 库上算好、删低方差列、按列 z-score 标准化； 药物描述符 → 一个 50 维条件向量，剂量（log）→ 1 维，两者拼接后进入条件 Monge 映射。

损失函数：Sinkhorn 拟合损失（把映射后的对照分布与真实处理分布对齐） + Monge 正则项（约束映射是一个好的最优传输映射，Euclidean 代价）。 没有药物分类损失，也没有逐细胞配对误差；训练是分布级、无配对的。

剂量：log 剂量作为条件向量的一部分；模型学习“剂量如何改变整个细胞分布的搬运方式”。

对应的生物医学 / 化学含义

chemCPA：学习“化学性质 → 转录效应”的映射

RDKit 描述符概括了分子量、脂溶性、极性、氢键、环数、官能团等性质。MLP 学的是： 哪些理化性质组合，会把细胞从基线状态推到哪种转录状态。 剂量网络再学“同一药物在不同剂量下效应放大多少”。

对抗项的作用是让“基础细胞状态”尽量不包含药物身份，从而把药物效应逼到药物向量里。 但这不等于学会了机制：32 个维度没有对应的通路/靶点标签，不能直接解释成“HDAC 抑制”或“MEK 抑制”。

冷药物：MLP 是描述符空间的平滑函数，所以任意药物都能得到一个向量； 但如果新药的化学描述符远离训练集（188 个 L1000 药物），这个向量就是外推，准确性没有保证。

CMonge：学习“化学/剂量 → 群体分布搬移”的映射

CMonge 不预测单个细胞的配对表达，而是学一个把对照细胞群体搬到处理细胞群体的映射。 50 维条件向量编码的是“需要怎样搬”：药物化学性质决定方向，剂量决定强度。

因为损失是分布级的，它能保留细胞异质性（不同细胞亚群可以有不同响应），而不只是预测一个平均表达谱。 这在生物医学上更接近“药物如何改变细胞群体构成/状态分布”的问题。

冷药物：RDKit 描述符对任意 SMILES 都可计算，所以结构上可编码； 但条件 MLP 是在 187 个 SciPlex 药物（以及 4i 的 35 种治疗）上训练的，全新化学型仍是外推。 MoA 分支看起来更“生物学”，但它需要该药的处理细胞，不能用于纯结构冷启动。

与 PerturbNet 的关键区别

PerturbNet 的 ChemicalVAE 是单独预训练的：在 ZINC 约 25 万个分子上做 SMILES 重构， 所以它的化学编码器先学了一套“分子长什么样”的通用表示，再接到扰动预测上。 chemCPA 和 CMonge 的 MLP 没有这个化学预训练阶段：RDKit 描述符是固定的， MLP 只由“表达/分布预测是否准确”来驱动。这也是为什么前者更像“通用化学表示 + 响应适配”， 后两者更像“为当前药物-响应数据集定制的化学投影”。

一句话：chemCPA 的药物 MLP 是“RDKit 描述符 → 32 维转录效应向量”， 由 Gaussian NLL 重构损失（加对抗解耦）训练；CMonge 的条件 MLP 是“RDKit 描述符 + 剂量 → 50 维 OT 条件向量”， 由 Sinkhorn + Monge 损失训练。两者都没有靶点/通路监督，学习到的是预测性化学-响应映射， 不是可解释的机制模型。

能否直接在 CM 数据集上训练，而不用单独训练药物编码器？

对 chemCPA 和 CMonge：可以。两者的药物编码器都不是“先单独训练好再冻结”的， 而是和响应模型一起端到端训练；RDKit 描述符只是固定的特征工程。但它们各自还有别的“单独训练”环节， 以及数据格式、剂量、单细胞/ bulk 的前提条件。

直接回答：chemCPA 和 CMonge 都可以直接在 CM 数据上训练，不需要单独预训练一个“分子 → 向量”的神经网络。 chemCPA 的 194→32 MLP 跟 VAE 一起训练；CMonge 的条件 MLP 跟 OT 映射一起训练。RDKit 描述符是离线算好的固定特征，不是训练出来的。

chemCPA 在 CM 上的最小训练流程

  1. 准备 AnnData：每个样本一行，包含表达矩阵、drug、dose、cell_type（如有）、control 标记。
  2. 给每个药配 SMILES：用 RDKit 算 194 维 2D 描述符，删低方差列、z-score；按 CM 药物顺序建立 drug_embeddings 表。
  3. 设置 num_genes 为 CM 的基因数；编码器/解码器从头训练（或只在基因维一致时复用公开权重）。
  4. 联合训练 ComPert：Gaussian NLL + 对抗项；药物 MLP 与 VAE 一起更新。不需要单独的化学预训练。
  5. 冷药物划分：按药物（最好按骨架/化学簇）留出测试药；确保训练中没有该药的处理样本。

如果要用公开 checkpoint 初始化：只能复用药物 MLP / doser 作为初始化；188 行药物表要替换成 CM 药物，32 维潜空间需在新 VAE 上微调对齐。

CMonge 在 CM 上的最小训练流程

  1. 准备 AnnData：对照细胞 + 处理细胞；每个条件有 drug、dose；每个条件要有足够多的细胞来估计分布。
  2. 算 RDKit 特征：194 维 2D 描述符，删低方差列、z-score；剂量用 log(dose)。
  3. 先训练 AE：把 CM 基因空间压到低维潜空间（这是基因空间自编码器，不是药物编码器），然后冻结。
  4. 训练 CMonge：条件 MLP + 传输映射，损失 = Sinkhorn + Monge；不需要药物分类标签。
  5. 冷药物划分：按药物留出；没有该药处理细胞的条件下，只能做结构外推。

CMonge 的 demo 是 100 基因、3 个药、类别剂量；换到 CM 需要改 dataloader/config。若 CM 是 bulk（每个条件只有一个表达向量），CMonge 的“分布搬运”没有足够细胞，不建议作为主模型。

四个必须确认的前提

  • SMILES 是否齐全：chemCPA / CMonge 的冷药物能力依赖 SMILES；没有结构就只能用药物 ID（CPA 类），不能做结构冷启动。
  • CM 是单细胞还是 bulk：CMonge 需要多个细胞/条件来估计分布；bulk 数据不适合。chemCPA 可以把每个 well 当样本，但会丢失细胞异质性。
  • 剂量是否连续/多档：chemCPA 原生支持连续剂量；CMonge 的 RDKit 分支可把 log 剂量作为条件，但 demo 的 dataloader 是类别条件，需要改。
  • 冷药物划分是否干净：如果用 chemCPA 公开 checkpoint 初始化，而 CM 测试药与 L1000 188 药重叠，会引入泄漏；公平评估应只用 CM 训练数据，或排除重叠药物。

一句话：chemCPA 和 CMonge 都可以“直接在 CM 上训练、无需单独训练药物编码器”； chemCPA 是“VAE + 药物 MLP 端到端”，CMonge 是“AE + 条件 OT 映射端到端（AE 单独训练，但不是药物编码器）”。 唯一真正的例外是 PerturbNet：它的 ChemicalVAE 是单独预训练的化学编码器，不能从 CM 数据里顺便学出来。

01PRnet

药物编码模块

  • 输入：化合物的 SMILES 结构 + 剂量。
  • 表示：rFCFP（rescaling functional-class fingerprint），每个化合物 1024 bit；剂量通过对指纹做尺度变换进入同一向量。
  • 网络：1–2 个化合物的指纹拼接 → MLP（128 维）→ 64 维扰动向量 c。
  • 关键点：没有“每个药一个 ID 嵌入”，因此新化合物只要给 SMILES 就能编码。
注意：代码里的 10 维 n 是高斯噪声，不是剂量；剂量在 rFCFP 里。

主预测模块

  • 结构：扰动条件生成模型（VAE 风格）。
  • 编码器输入 [基线表达 x；药物向量 c] → 64 维潜变量 z。
  • 解码器输入 [z；c；10 维噪声 n] → 每个基因的均值与方差。
  • 损失：Gaussian NLL（代码中的 GUSS），不做对抗解耦。
  • 输出是处理后表达谱，不是 Δ 表达。
模型很小（0.55 M 参数），x_dimension 可配置；论文用 978（bulk）/ 5,000（单细胞）。

02CPA

Lotfollahi et al., Molecular Systems Biology 2023 · 组合扰动 · 未见剂量 / 细胞类型 / 药物

药物编码模块

  • 基础 CPA：每个药一个 药物嵌入（维度 = 潜变量维度；Kang 为 64）。默认是可学习随机嵌入；可选地用 Morgan 指纹初始化后冻结。
  • 剂量：每药一个剂量网络（sigmoid / log-sigmoid / MLP），把剂量映射成 0–1 的缩放系数，乘到药物潜变量上。
  • 协变量：细胞类型等用可学习嵌入，与药物潜变量相加。
  • 冷药物：原生 CPA 需要该药的嵌入；论文的冷药物结果依赖把 chemCPA 的化学编码器接进来。
所以 CPA 本身更像“组合扰动 + 剂量”的加性模型，而不是从 SMILES 学化学的模型。

主预测模块

  • VAE：编码器把处理/对照表达压到低维基础潜变量 z_basal（默认 128 维；Kang checkpoint 实际为 64 维）。
  • 加性组合：z = z_basal + z_drug(dose) + z_covariate。
  • 解码器把 z 还原成基因表达；似然可选 NB / ZINB / Gaussian。
  • 对抗器：额外分类器试图从 z 预测药物/协变量，训练时反向抑制，促使潜变量“去身份化”。
  • 支持组合药（多个药物潜变量相加）。

03chemCPA

Hetzel et al., NeurIPS 2022 · 冷药物 + 冷细胞系组合 · 单细胞

药物编码模块

  • 默认：RDKit 2D 描述符 → MLP（embedding_encoder）→ 与潜变量同维的药物嵌入。
  • 可选预训练：ChemicalVAE、JT-VAE、GROVER 等分子表示，替换 RDKit 输入。
  • 剂量：每药一个 doser 网络，把剂量缩放后乘到药物嵌入上。
  • 对抗器：药物分类器迫使潜变量不保留药物身份，从而把“药物效应”和“身份”分开。
化学编码器是基因空间无关的；解码器不是。因此换到 20,570 基因时，编码器可复用，解码器必须重训。

主预测模块

  • ComPert VAE：编码器把表达压到低维潜变量；解码器还原表达。

  • 输出是细胞群体分布，不是单个平均细胞。

06scVIDR

Kana et al., Patterns 2023 · 剂量-响应 · 潜空间算术

无化学编码 预训练权重未就位 剂量插值

药物编码模块

  • 没有化学结构编码器，不读 SMILES。
  • 药物/剂量的作用表示为潜空间位移 Δz：同一细胞类型下，“处理组平均潜变量 − 对照组平均潜变量”。
  • 连续剂量用 log 线性插值：Δz(d) = Δz_max · log1p(d) / log1p(d_max)。
  • 不同细胞类型有各自的响应差异，模型用回归项估计。

  • VAE：2,000 基因 → 隐藏 800 → 10 维潜变量；解码器对称。
  • 训练目标：重构 + KL；论文的 scVIDR 还加入潜空间回归，用于处理剂量与细胞类型差异。
  • 预测：z_target = z_control + Δz(drug, dose, cell type)，再解码成表达。
  • 本次默认配置 4,541,620 参数。

已有权重

  • 仓库 README 说“same names as listed above”的模型可提供预训练版本，但权重未随仓库分发，也未在本机就位。

本次 setup 实际跑了什么

  • 训练 180 个合成细胞、2 epoch。

09DECANT

Liu et al., Bioinformatics 2026 · 机制-上下文解耦 · 药物级留出

无化学编码 无权重 / 无数据 转导式（需要处理细胞）

药物编码模块

  • 没有 SMILES / 化学结构编码器。
  • 药物表示来自“处理组 − 对照组”的转录响应袋：细胞编码后做注意力池化，得到扰动摘要。
  • 通过门控减去上下文投影，得到“机制潜变量”；再用药物原型记忆库（prototype bank）约束同一药的表示。
  • 可选：用 LINCS/CMap 教师原型做蒸馏，改善机制空间的生物学对齐。
关键：预测一个“未见药物”时，模型仍然需要该药处理过的细胞袋；这不是只给结构的零样本预测，而是转导式评估。

主预测模块

  • 细胞编码器：基因 + 程序（program）双通道 → 每个细胞一个 token。
  • 注意力池化：分别汇总处理组与对照组，得到群体表示。
  • 机制/上下文解耦：机制头 + 上下文门控 + 残差头；上下文包括细胞系、log 剂量、处理时间。
  • 解码器：先预测 program 响应，再预测 gene 响应（Δ 表达）。
  • 本次配置 162,384 参数，2,000 基因、50 个 program。

已有权重

  • 没有 checkpoint，也没有处理好的 cell bag 数据；仓库是复现骨架。

  • 2,000 基因、4 个样本、两个剂量（1 / 100）前向。

五个必须警惕的陷阱

1. 论文数据 ≠ 本项目数据

论文多在 L1000、sci-Plex、Kang、4i 等数据上评测；本项目的 CM 数据、基因空间（20,570）、药物集合、剂量范围都不同。 论文成绩只能说明“方法在那个数据上可行”，不能直接外推。

2. “药物级留出”不等于“化学冷启动”

DECANT 的测试药物在训练中没见过，但预测时仍使用该药的处理细胞袋；CPA 的原生模型需要每个药的嵌入； biolord 的默认模式也是药物类别。真正只给结构的，是 PRnet（rFCFP）、chemCPA（RDKit）、PerturbNet（ChemicalVAE）、 Squidiff（rFCFP）和 CMonge（RDKit 版本）。

3. R² 会被“平均效应”抬高

扰动数据里大多数基因不变，所以“预测所有基因都等于对照”也能得到不低的 R²。论文因此常同时报告 DEG R²、 Δ 表达 Pearson、Wasserstein、MMD 等。PerturbNet 的 sci-Plex 结果里，linear baseline 的 median R² 也有 0.954， 就是典型例子。

4. 基因空间决定“能不能比”

PRnet 的 978、chemCPA 的 977/2,000、CPA 的 5,000、PerturbNet 的 5,087、本项目的 20,570 不是同一套基因。 不同基因空间上的 R² 不能直接排名；必须先统一基因集、预处理（log2(CPM+1) 还是 counts）和评估单元（bulk / pseudobulk / 单细胞）。

5. “能加载”不等于“能预测”

chemCPA 的 8 × 977 是合成 batch 前向；PerturbNet 的 (2, 10) 是潜变量前向；scVIDR / Squidiff / DECANT 是合成数据或随机权重。 这些 smoke 只证明代码路径与权重兼容，不证明生物学预测能力。

给非计算读者的术语表

SMILES
用一串字符表示分子结构，例如 CC(=O)Oc1ccccc1C(=O)O（阿司匹林）。模型用它作为药物输入。
指纹（fingerprint）
把分子结构压成一段固定长度的 0/1 或数值向量。rFCFP、Morgan、RDKit 描述符都是不同“翻译方式”。
潜变量（latent）
模型内部压缩后的低维坐标，不是直接可读的基因。可以理解为“细胞状态/药物效应”的抽象坐标。
VAE（变分自编码器）
一类“压缩再还原”的生成模型：编码器把表达压到潜变量，解码器再还原。常用于单细胞扰动预测。
cINN（条件可逆网络）
一种可逆的神经网络，能把“药物潜变量”映到“细胞潜变量”，也能反推。PerturbNet 用它做概率搬运。
最优传输（OT）
把一组细胞（对照分布）“整体搬运”成另一组细胞（处理分布）的数学框架。CMonge 用条件 OT。
扩散模型（diffusion）
先从噪声开始，逐步去噪生成表达谱。Squidiff 用条件 DDIM 做这件事。
DEG
差异表达基因（differentially expressed genes）。只看这些基因上的指标，比看全基因更严格。
冷药物 / 冷细胞
训练中完全没见过的药物 / 细胞类型。冷药物是药物发现中最有价值的泛化场景。
转导式（transductive）
预测时使用了目标样本本身的信息（例如该药处理过的细胞），而不是只给结构。泛化难度低于真正的零样本。

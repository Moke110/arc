# AGENTS.md — stage2/01_setup

Routing index. Purpose, results and reproduce commands live in `README.md`; the
human report is `model_architecture_weights_benchmarks.html` (step level).

```
stage2/01_setup/execution/<model>/{README.md,run.sh,smoke.py,env.lock,output/}
```

One directory per deployed model; `<model>` keeps the lowercase environment name.

- `execution/prnet/` — LINCS 978 demo, `run_prnet.py`; **setup-only**.
- `execution/cpa/` — Kang checkpoint load + predict.
- `execution/chemcpa/` — load-only forward, public L1000 977/2,000 checkpoint.
- `execution/biolord/` — from-scratch train on `GSM_new.h5ad`; local `.venv`.
- `execution/perturbnet/` — released cINN + ChemicalVAE latent forward.
- `execution/scvidr/` — synthetic 2,000-gene train + continuous dose.
- `execution/squidiff/` — 2,000-gene drug-structure forward.
- `execution/cmonge/` — official sciplex demo train + evaluate.
- `execution/decant/` — synthetic 2,000-gene forward, two doses.
- `execution/perturbdiff/` — native synthetic train/save/reload/DDIM setup; tenv admission is separate.

Run from the repository root: `bash stage2/01_setup/execution/<model>/run.sh`.
Every run writes `execution/<model>/output/run.log` (plus `meta.json` for six
models); prediction arrays are regenerated by a rerun and gitignored. Each run
entrypoint chain finds the repo root by walking up to `.git` (in `run.sh` or
`smoke.py`) — do not add `../..` arithmetic.
Do not edit the vendored model tree under `pert_model/` to make a run work;
adapters live in the run-card directory. Preprint models (X-Pert, DORA, BaiZe, PerturbLDM) are not
part of this stage.

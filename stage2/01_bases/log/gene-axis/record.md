Scope: ticket #183 (parent #177, resolves the open questions of #175 under the
re-scoped user instruction). Original round: worktree `gene-axis-06`, branch
`codex/gene-axis-06-evidence`, based on a `dev` that already carries Gene axis

**Review-fix round (2026-11-13, branch `codex/gene-axis-08-review-fixes`).** An

arrays with the row positions of the fused table, which is sorted by

per-source quota, no direction rule and no animal-source weight (those stay in

opens a truth or Heliste label file. The only tenv input is the published

## Review fixes at the root

All six index-space findings share one root cause: `fused_rank.csv` is sorted by
`fused_rank` before these consumers run, and `fused_order(fused.fused_rank)` on
the sorted frame is the identity permutation, so gene-indexed arrays were being
read at row positions. The fix is a single contract: every consumer of a
per-gene vector now takes a **gene-indexed** vector; the sorted columns are
scattered back once with `align_to_gene_index`, and the regression fixture
`IndexSpaceTests` uses a case where fused-rank order differs from `gene_index`
order.

| finding | old behaviour | fixed behaviour | headline old → new |
|---|---|---|---|
| 1. `tenv_non_hvg_curve.csv` | non-HVG share of the first N genes in `gene_index` order | share of the true fused top-N | at N=2,000: K=1000 0.9390 → **0.9130**, K=2000 0.8865 → **0.8230**, K=5000 0.7195 → **0.6095** |

| 4. `_answers` Q3 tie-break | prose said "tie-break `gene_index`"; the code (and product) tie DEG-count ties by fused rank | prose now says exactly "descending count, ties by ascending fused rank" (kept: it is deterministic, consistent with the fusion, and more informative) | Spearman stays **0.8095**; the `gene_index` tie-break gives 0.6791 / top-500 0.204 |

## Recipe of record

The authoritative recipe strings, constants and per-input digests are in
`output/gene-axis/manifest.json`. Summary:

- **HVG** — Seurat-style normalized dispersion on each item's deposited log
  expression (per-gene mean over finite samples, sample variance / mean, log
  dispersion z-scored in 20 equal-width `log1p(mean)` bins, singleton bins score
  1, undefined dispersion sorts last, source-row order as tie-break). Same
  family as `output/api/bases/hvg.py`; deliberate difference: no `expm1`
  recovery because the disease matrices are heterogeneous non-invertible log
  scales (voom log2 abundance, log2(RPKM+1), log2(CPM+1), log2(CP10K+1)), so the
  statistics are computed on the deposited log values directly. The ranking is
  over the source's **whole measured transcriptome** (every matrix row, not only
  the rows that resolve to the axis).
- **Source HVG set and share** — a source's declared set at size K is its top-K
  source rows by that ranking. `n_hvg_total = min(K, n_source_genes)` (the
  declared set size; `n_hvg` keeps its old column and equals it),
  `n_hvg_on_axis` is the number of distinct frozen-axis genes in the set,
  `hvg_share = n_hvg_on_axis / n_hvg_total`, and
  `hvg_density = n_hvg_on_axis / n_axis_expression`. The overlap table uses
  K ∈ {1000, 2000, 5000}; the reported summary uses the declared K=2000.
- **DEG** — continuous per-contrast `|log2FC| * -log10(padj)` with `padj`
  floored at 1e-300; NA `padj` is treated as non-significant (score 0) but stays
  in the measured set; multi-contrast sources collapse per gene by **maximum**
  effect and keep `n_contrasts_supporting` (padj < 0.05).
- **Ranks** — within-source only. Measured genes rank 1..`n_measured` by
  descending score with `gene_index` tie-break; unmeasured = `n_measured + 1`
  raw rank and `rank_norm = 1.0`. No cross-source comparison of effect sizes.
- **Fusion** — unweighted sum of `rank / n_measured`; fused order ascending
  `rank_sum` with `gene_index` tie-break. `rank_sum_animal_half` and
  `fused_rank_animal_half` re-weight only GSE160516/GSE108940 at 0.5 and are a
  reported sensitivity, never the chosen rule.
- **Direction** — per gene the per-source maximum-effect DEG row (the
  multi-contrast maximum) gives the sign: `direction = sign(log2FC)` of the
  largest cross-source effect, 0 when no source reports an effect
  (`n_unsupported`). The top-N composition is reported under two orderings:
  `symmetric` = first N genes by ascending `fused_rank`; `max_abs_log2fc` = N
  genes with the largest `max_abs_effect = max over reporting sources of
  |log2FC|`, ties broken by ascending `fused_rank`. Exact cross-source effect
  ties are counted (`n_direction_ties`).
- **Overlap** — tenv HVG sets are the published descriptive top-K; a source HVG
  set is its declared top-K over its own measured transcriptome, projected to
  the axis; a source DEG set is `padj < 0.05` on the winning contrast. All sets
  are `gene_index` sets and the reported rank positions are true fused ranks.
  Multi-way intersection rows report the size and fused ranks only (no Jaccard)
  with a `note`.
- **Tenv non-HVG curve** — for N = 1..18,164 the fused top-N are the first N
  genes by ascending `fused_rank`; the curve reports the share whose published
  tenv HVG rank exceeds K for K ∈ {1000, 2000, 5000}.
- **Q3 tie-break** — the DEG-count ranking is descending
  `n_sources_deg_significant` with **ascending `fused_rank`** as the tie-break
  (declared; a `gene_index` tie-break gives a different, weaker ranking).
- **Inflection** — Kneedle online `S=1.0` (first interior local maximum of the
  normalized arc `y_norm - x_norm` attaining the global arc maximum) plus the
  second-difference peak of the same normalized curve inside the declared
  decision range `[min_n=100, n]`; an inflection is accepted only when both
  candidates agree within 25% and the knee exceeds 0.01 normalized units.

   the disease-consensus top is not a tenv-HVG top. That is the central decision
   input of this product.

6. **Top-N direction composition** (`direction_summary.csv`, N = 500/1000/2000/
   3000/5000; two genuinely different rules — see the recipe; ties counted and
   broken by the declared source order):

   | N | up (symmetric) | down (symmetric) | up (max \|log2FC\| ranking) | down (max \|log2FC\|) | unsupported | ties |
   |---:|---:|---:|---:|---:|---:|---:|
   | 500 | 0.5260 | 0.4740 | 0.8680 | 0.1320 | 0 / 0 | 0 |
   | 1,000 | 0.5250 | 0.4750 | 0.8840 | 0.1160 | 0 / 0 | 0 |
   | 2,000 | 0.5380 | 0.4620 | 0.8625 | 0.1375 | 0 / 0 | 0 |
   | 3,000 | 0.5343 | 0.4657 | 0.7900 | 0.2097 | 0 / 1 | 8 |
   | 5,000 | 0.5202 | 0.4798 | 0.7082 | 0.2914 | 0 / 2 | 16 |

   The symmetric up share is 52–54%, a mild up bias; ranking by effect magnitude
   is far more strongly up-biased at the top (87% up at N=500) but that bias
   fades with N. Up/down rank symmetry: 8,889 up-significant and 7,857
   down-significant genes; across all significant genes the **down** set has the
   better median fused rank (8,031) than the up set (8,779), while the up share
   is still higher inside the fused top-N. The ranking is therefore mildly
   up-biased at the top but not symmetric overall.

## The three #175 questions (also pinned in `manifest.json → answers`)

1. **Chronic-remodelling vs HF overlap difference.** HF×HF Jaccard is 0.4255,
   while the AF/HHD chronic-remodelling pair is 0.0043 and the four HF×remodelling
   cross pairs average 0.0233. The HF transcriptomes agree with each other and are
   nearly disjoint from the two remodelling sources; tenv-HVG overlap with the HF
   sources (972 / 735 genes at K=2000) is larger than with AF/HHD (59 / 10).
2. **Up/down rank symmetry.** In the fused top-N the up share is 52–54%
   (symmetric) and 71–88% (max |log2FC| ranking), with 0–16 exact direction ties.
   Across all significant genes the up set has the *worse* median fused rank
   (8,779 vs 8,031 for down); the ranking is only mildly up-biased at the top, not
   symmetric.
3. **Effect×replication vs DEG-count agreement.** Ranking genes by the number of
   sources that report them significant (descending count, tie-break **ascending
   fused rank**) agrees with the fused effect×replication ranking at Spearman
   0.8095 and top-N overlap 0.616 / 0.555 / 0.4775 / 0.4477 / 0.7604 at
   N = 500 / 1000 / 2000 / 3000 / 5000 (308 / 555 / 955 / 1,343 / 3,802 genes).
   Replication count and effect-magnitude evidence mostly agree at the very top
   and diverge most at N≈3000. The tie-break is a real choice: a frozen
   `gene_index` tie-break instead gives Spearman 0.6791 and top-500 overlap 0.204.

## Deviations and judgment calls (all documented in the code/manifest)

- **Which per-source rank enters the fusion.** tenv contributes its published
  HVG rank; every disease/animal/pert source contributes its DEG rank (its own
  HVG rank is still computed for the 5 expression items and reported in
  `source_summary.csv`, `overlap.csv` and the per-source intermediates). This
  keeps the fusion about disease responsiveness while retaining the variability
  evidence.
- **Source HVG set size.** Declared `K=2000` as a *reporting convention* so a
  tenv set and a disease-source set are compared at one size; it is not the axis
  `N`. The overlap table additionally compares at K=1000 and K=5000.
- **Direction is not significance-filtered.** The composition rule uses the sign
  of the maximum-effect per-gene DEG row across sources (the per-source
  multi-contrast maximum); a gene is `n_unsupported` only when no source reports
  an effect. The #175 symmetry counts separately require `padj < 0.05` in at
  least one source.
- **Q3 tie-break.** The DEG-count ranking ties by ascending fused rank (not by
  `gene_index`); the manifest, this record and the acceptance record say so, and
  `deg_count_agreement` documents both alternatives.
- **GSE244740 derivation.** The item ships counts only, so the adapter computes
  log2(CPM+1) over all source genes, a two-sample Welch t-test per gene and
  within-contrast BH. Controls are the **same-plate** DMSO wells: the three
  anthracyclines are on one plate (S4881Nr8) with 22 DMSO wells, while all other
  plates' DMSO would be batch-confounded. All dose indices of a drug are pooled
  (the deposit carries relative `Con` indices, not µM). This is a declared
  ranking method, not a released DEG product; the later `source_summary`
  numbers inherit it.
- **DToxS collapse.** 22 upstream `CTRL-<code>` tables (DAU 6, DOX 4, EPI 4,
  IDA 4, TRA 4; no MTX in this deposit) are read as-is and collapsed per gene by
  the shared max-effect rule; `contrast` is the upstream table stem so the cell
  line/plate remains visible.
- **Mouse→human chain.** homologene `mouse2human` (inTax 10090) via the pinned
  `arc` R, then the frozen-axis symbol resolver; one mouse symbol resolving to
  more than one on-axis gene is dropped and counted, many-to-one collapses by
  max effect. The table is pinned as `mouse_human_orthologs.csv`; the app-log
  `AveExpr`/`t` columns are not used. `build_mouse_orthologs.R` writes a
  candidate under `execution/gene_axis/` (candidates stay outside formal
  `output/`, ADR 0062), compares its sha256 with the accepted table, and
  replaces the accepted path only when byte-identical or when `--args --accept`
  is passed; the run in this round was byte-identical and left the table
  unchanged.
- **Second-difference search floor.** The leading 100 positions are excluded from
  the second-difference search (`min_n=100`); without that floor the curvature of
  the two leading outlier genes dominates every knee test. This is a declared
  parameter in `inflection.json`, not a tuned result.
- **Figure data ownership.** The build writes the complete plotted-values CSV;
  the PNG is rendered by the separate CSV-only script and its digest is pinned
  here and in `inputs.json` (the build cannot pin a PNG it does not render).
- **Ticket test command.** The acceptance line `pytest -p 'test_gene_axis.py'` is
  not a valid pytest invocation (`-p` takes a plugin name); the file is run with
  `python3 -m pytest -q stage2/01_bases/execution/tests/test_gene_axis.py`.

## Limitations

- `GSE160516` has no sample count in its local DEG interface (the CEL inputs are
  not redistributed), so `n_samples` is empty for it; `GSE108940` reports 12 from
  the item's build-script design (6 IR + 6 sham).
- The HVG share now measures how much of a **source's own** variability evidence
  lands on the axis; it is 1.0 for tenv by construction (the published ranking is
  already axis-restricted) and is not comparable across sources as "variability
  of the axis".
- Several source ranks are noisy at the top by construction: GSE141910's leading
  HVGs are sex-linked (XIST/EIF1AY), and the `K=2000` HVG sets are a reporting
  convention, not evidence that every source has the same variability structure.
- GSE108940 contributes essentially no significance evidence; its column is
  effect-score-driven and its leave-one-source-out effect is checked, but a
  reader should not treat it as a replication source.
- The animal half-weight column is reported, not chosen; #173 owns that decision.
- No stochastic tolerance is claimed: the whole pipeline is deterministic and
  file-integrity hashes are recorded separately from the metric values.

# Isolated CMonge v2 protocol (not activated)

`cmonge-v2-full-validation-fixed-draws` retains the native model, Sinkhorn +
Monge objective, optimizer, cosine schedule over 10,000 iterations, and batch512.
Only validation, checkpoint cadence and stopping change. The independent GPU
entry point is `execution/script/cmonge_v2_gpu_adapter.py` with its own identity
sidecar and `v2.config.json`; it never imports the frozen v1 adapter.

Every 50 iterations (previously 100), and at the final iteration, evaluate all
138 held-out drug-dose groups in sorted group order. Each group uses512 draws
with replacement from its approved held-out wells. Reset the separate seeded
validation RNG each event, so all events use the same draws and training draws
are unchanged. The selection metric is the equally weighted arithmetic mean of
native batch objectives across groups. Sequential group access bounds memory.
This is an adapted validation protocol, not an upstream early-stop claim.

Keep the strict lowest validation objective as the prediction checkpoint.
Independently initialize the patience reference at iteration500, then stop after
10 subsequent eligible checks without a relative improvement of at least0.001
against that reference (denominator=max(abs(reference),1e-12)). A qualifying
improvement resets patience. The earliest stop is iteration1000. Thus warmup is
5% of the native10,000-iteration schedule and the earliest stop10%; the relative
0.1% threshold expresses improvement in the native objective's own scale,
without borrowing PerturbDiff diffusion-loss units or tuning on test scores.
These predeclared values establish a reproducible protocol, not proven optimal
statistical convergence criteria.

Each event writes `latest.msgpack`, updates `best.msgpack` on any strict minimum,
and publishes `history.json`. Snapshots contain parameters only and are explicitly
prediction-only, not resumable. Restart from the declared seed; all legacy/retry
wall time consumes the original14,400-second cap. The request must carry a finite
explicit `prior_training_seconds`; resume requests and exhausted/missing debits
are refused. The adapter checks its remaining training deadline before steps,
between validation groups and before inference. A separate externally reviewed
watchdog and conservative migration ledger are still required for production.

Legacy fold0/seed17 attempt walls total13975.509756658023 seconds, leaving
424.490243341977 seconds. Seed42 totals9056.932746226995 seconds, leaving
5343.067253773005 seconds. These are conservative sums from the original

cannot plausibly reach the predeclared minimum stop iteration: even prior native

or count the old completed model as a new v2 completion. Keep legacy binaries,
identities, logs and histories separately with their original hashes.

in39.006907 seconds and one complete138-group validation in71.577104 seconds
(~0.518675 seconds/group). A simple maximum-schedule projection is about6.14h,
so reaching10,000 is unlikely inside4h; early stopping or an honest terminal
budget outcome is required. This is throughput evidence, not convergence or a
formal model result. The51-iteration/two-event probe hit its180s external limit
while validating the second event; its first event snapshots/history survived,
but it produced no completed checkpoint/prediction. Native cooperative signal
handling finished the current group, yielding185.77s total wall; production

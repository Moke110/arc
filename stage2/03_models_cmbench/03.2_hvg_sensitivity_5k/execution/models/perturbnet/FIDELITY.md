> Derived from `stage2/03_models_cmbench/03.1_cold_drug_18k/models/perturbnet/FIDELITY.md`; the gene-space rows are re-declared for the 5,000-HVG sensitivity axis (ADR 0028).

Classes follow ticket 09: `config_only`, `adapter_extension`, `recipe_omission`,
`recipe_substitution`. Every row states an expected effect; the target is zero
*undeclared* deviations. `reproducibility_break` is not used: the authors'
Python 3.7 / torch 1.13.1 / scvi-tools 0.7.1 environment was built and used as
pinned (ticket 10's py3.10 fallback was **not** needed).

# CLAUDE.md — hg/

## Purpose

Heterogeneous Graph Neural Network (HeteroGNN) for drug embedding generation. Trains on a drug-gene heterogeneous graph via contrastive learning (InfoNCE loss) to produce 256-dim biological drug embeddings consumed by XPert.

## Environment

- Conda env: `xpert` (Python 3.13, PyTorch 2.12, PyTorch Geometric 2.8)

## Key Workflows

### Training from scratch (8,981 drugs)

```bash
cd hg/
bash run.sh                                    # Default params
bash run.sh --device cuda:0 --epochs 500
# Output: model/<timestamp>/global_fold_early_stop.pth
```

Default hyperparameters: num_layers=3, hidden_dim=256, out_dim=256, num_neighbors=[10,5,3], batch_size=1, epochs=300, patience=30, lr=5e-4, temperature=0.5, num_neg_samples=3.

### FDA drug embedding generation (full pipeline)

```bash
# Step 1: Query DTI data from ChEMBL
python -m src.query_dti_fda --start 0 --end 2123 --min-pchembl 6.0

# Step 2: Compute DDS edges
python -m src.compute_dds_fda

# Step 3: Fine-tune on extended graph
python -m src.finetune_hg --device cuda:0 --lr 5e-5 --epochs 50 \
    --update-xpert-embeddings
```

### Resume from checkpoint

```bash
bash run.sh --global_saved_model model/<timestamp>/global_fold_early_stop.pth
```

## Model Architecture

- HeteroGNN: 3 HeteroConv layers, each with SAGEConv for all edge types
- Input: gene (512→256 linear), drug (512→256 linear)
- After each HeteroConv: ReLU activation
- Relation predictors: 3 MLP heads (Linear(512→1)) for DTI, DDS, PPI
- Node types: Drug, Gene; Edge types: PPI, DTI, DDS
- Hidden/Output dim: 256; ~3M parameters

## Graph Data

- PPI: 901,260 weighted gene-gene edges (STRING, score>700)
- DTI: 12,890 drug-gene edges (training) + 3,984 (FDA extension, ChEMBL pChEMBL≥6.0)
- DDS: 287,834 drug-drug edges (training) + 7,659 (FDA extension, Tanimoto>0.5106)
- Drug nodes: 8,981 training + 2,123 FDA = 11,104 total; 512-dim UniMol mol features
- Gene nodes: 19,392; 512-dim PPI-derived features; 978 are L1000 landmarks

## Loss Function

InfoNCE contrastive loss (temperature=0.5):
```
pos_sim = cos(z_i, z_j) / τ
neg_sim = cos(z_i, z_neg) / τ
loss = -log(exp(pos_sim) / (exp(pos_sim) + Σexp(neg_sim)))
```
Positive pairs = real edges; negatives = randomly sampled non-edges (3-5 per positive).

## Fine-tuning Design

Full-graph training (no NeighborLoader). Per epoch: full forward pass → sample DTI(all)/DDS(20K)/PPI(50K) edges → InfoNCE loss → backprop. Low LR (5e-5) preserves training embeddings (cosim>0.95). FDA embeddings then quantile-interpolation mapped to match training drug norm distribution.

Level_1_data_methods	FASTQ sequence data files of 914 PromoCell samples are generated by Illumina HiSeq 2500 sequencing system.
Level_1_data_QC_methods	A minimum of reads per sample is required for all sequenced samples.
Level_1_data_creation_method	The sequence file of each PromoCell sample is created by demultiplexing the raw FASTQ data files for both the sequence reads and the barcode reads from all sequencing lanes generated by Illumina HiSeq 2500 sequencing system and then splicing the sequence and barcode parts to a complete single 3'-end sequence read tagged with its UMI barcode for all the reads of each sample.
Pre-alignment_QC_method	All samples to be analyzed must meet the requirement of a minimum read depth.
Criteria_for_removing_samples_based_on_pre-alignment_QC	A minimum read depth of 2-million reads per sample
Samples_not_passing_pre-alignment_QC	Removed
RNAseq_trimmer_software	N/A
RNAseq_alignment_tool	STAR
RNAseq_alignment_tool_parameters	--runMode alignReads --outSAMattributes NH HI NM MD AS nM jI jM --genomeDir ${STAR_REF_GENOME_INDEX_DIR} --outSAMtype BAM Unsorted --outFilterMultimapNmax 10 --outFilterMismatchNmax 10 --outMultimapperOrder Old_2.4 --outSAMunmapped Within
RNAseq_alignment_gtf	ncbiRefSeq.All.hg38.gtf
Post-alignment_QC_method	None
Level_3_data_methods	To generate the gene read counts tagged with unique molecular identifier (UMI) barcodes for of 914 PromoCell samples at this level, the following four steps are performed: 1) the FASTQ-format mRNA-sequence data files are aligned to the NCBI's RefSeq human reference genome library (hg38) by STAR program (version 2.5.3a); 2) the aligned sequence reads with redundant UMI barcodes are removed; 3) the aligned sequence reads with unique UMI barcodes are then counted by the featureCounts program of Subread (version 1.6.2) to generate the number of reads aligned to each reference gene and tagged with unique UMI barcodes for each PromoCell sample; 4) the raw gene read counts of each sample are converted to counts-per-million (CPM) reads with respect to the sample size and then normalized by the trimmed mean of M-values (TMM) method to create the normalized and uniquely tagged gene read counts for each PromoCell sample.
Level_3_data_QC_methods	The hierachical clustering method is used to cluster the multiple sample replicates at each drug treatment for each cell line according to their correlation coefficents and identify the outlier samples from sample clusters.
Criteria_not_passing_post-alignment_QC	None
Samples_removed_based_on_post-alignment_QC	null
RNAseq_quantification_tool	featureCounts
RNAseq_quantification_tool_parameters	-a ncbiRefSeq.All.hg38.gtf -F GTF -t exon -g gene_id -R SAM
Read_counts_qc	None
Criteria_for_removing_samples_based_on_read_counts_QC	null
Samples_not_passing_counts_QC	The samples identified as outliers by the hierachical clustering method with the cutoff correlation coefficient according to the specific sample clusters of the sample replicates at each drug treatment for each cell line.
Batch_information_and_batch_effect_adjustments	null
Replicate_aggregation_method	None
Level_4_data_methods	The data at this level is the differentially expressed genes at drug treatment for each cell line. The differentially expressed genes are generated by the edgeR program which compares the expression levels of two groups of sample replicates, the drug-treated group and the control group within each cell culture experiment at drug treatment for each cell line, by testing the statistical significance of the difference in their expression levels.
Level_4_data_QC_methods	A false discovery rate (FDR) value of 0.1 is used to identfiy the DEGs at each drug treatment for each cell line.
Statistical_analysis_software,_model,_parameters	edgeR

# AGENTS.md — pert_data

Index of the CM drug-perturbation data lake (raw/processed transcriptomic datasets + LINCS L1000 pretrain corpus). One line per entry; details live in each dataset's own files/reports.

- `dtoxs_primary/` — DToxS primary CM, released LINCS LDS-1593 well-level package (`Data/`, `Metadata/`, `ProcessingPipeline/`, `ReadMe.txt`, `LDS-1593.tar.gz`, `DToxS_summary.md`) plus frozen `v1-frozen/`.
- `dtoxs_ipsc/` — DToxS iPSC-CM (Hansen 2024): GSE217421 Conv + GSE217423 DGE GEO files (SuperSeries GSE217424).
- `gse244740/` — Rosell-Hidalgo ScreenSeq: processed counts + series matrix.
- `gse247541/` — Xu COVID-19 antivirals: raw counts + series matrix.
- `gse262419/` — Tsai TempO-Seq: 16 per-plate CSVs + hash CSV + series matrix.
- `xpert-l1000/` — XPert L1000 pretrain corpus (`data/` h5ads + `L1000_summary.md`).
- `annotation/` — pinned Stage 2 gene/compound annotation assets (HGNC complete set + public-registry compound snapshot; provenance and checksums in `annotation/README.md`).
- `tahoe/` — Tahoe-100M (HuggingFace `tahoebio/Tahoe-100M` pinned revision `349e2a55…`, CC0-1.0) **full atlas**, imported from the Windows HF snapshot on 2026-10-30: 3,388 expression shards (95,624,334 cells) + complete metadata incl. the authors' `pseudobulk_differential_expression` (1,026 shards), 428.8 GB; provenance/verification in `tahoe/Tahoe_summary.md`, contract in ADR 0029; the pseudobulk corpus is built by `stage2/04_tahoe_pretrain/script/build_pseudobulk.py`.
- `cm_drugs.html` — pert_data CM datasets compound audit: small-molecule counts, externally resolved SMILES (PubChem/ChEMBL, cross-verified) and pharmacology classes, plus the in-HG drug overlap report. Generated by `stage1/xpert-fda-miri-v3/03_cm_finetune_data/{compound_external_audit.py,drug_overlap_report.py}`.
- Removed (provenance only): GSE221595 (8 TKIs), GSE146095/GSE146096 raw GEO deposit.

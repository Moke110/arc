# CLAUDE.md

This file is the **LLM context index** for the `arc` project. It is loaded at the start of every conversation. Its purpose is to route the agent to the correct subdirectory CLAUDE.md based on the task, minimizing unnecessary file reads.

See [README.md](README.md) for the human-readable project documentation.

## CLAUDE.md vs README.md Convention

Every directory in this project maintains two documentation files:

- **CLAUDE.md** — LLM context index. English only. No markdown tables. No diagrams. Concise, machine-parseable structure: Purpose, Structure (file tree), Dependencies, Key Files (file → one-line purpose), Entry Points, Notes. Optimized for minimal token consumption during agent routing.
- **README.md** — Human project documentation. Chinese narrative with English technical terms. Uses tables, ASCII flowcharts, and diagrams for clarity. Explains goals, design rationale, methodology, and background.

**Loading rule**: Root CLAUDE.md is always loaded. Subdirectory CLAUDE.md files are loaded on-demand — the agent reads only the ones relevant to the current task, following index pointers from parent CLAUDE.md files. README.md files are NEVER loaded automatically; they are updated at the end of each conversation session for any directories whose CLAUDE.md was touched.

**Update rule**: At session end, update all CLAUDE.md files that were loaded during the session (to reflect any changes made), then update the corresponding README.md files.

## Project Goal

Predict drugs for myocardial ischemia-reperfusion injury (MIRI) treatment using AI and bioinformatics. Core workflow: predict transcriptional perturbation (978 landmark genes) on cardiomyocytes from small-molecule chemical structures, then rank drugs by MIRI efficacy score. Cardiotoxicity scoring is deferred from v1 (see `docs/adr/0004`).

## Pipeline

Drug SMILES → UniMol (3D molecular features) + HG (biological embeddings) → XPert (DEG prediction, 978 genes) → `miri_reposition/xpert-fda-v1/` (drug efficacy scoring, 3 scoring pipelines → integrated ranking)

## Category Taxonomy

The repository root is organized into four categories (see `docs/adr/0001`):

- **Dev-tool files** at root: `AGENTS.md`, `CLAUDE.md`, `README.md`, `CONTEXT.md`, `environment.yml`, `docs/`, `reference/`, `.agents/`, `.gitignore`.
- **Perturbation components** — category containers holding named instances:
  - `pert_data/dtoxs/` — DToxS drug perturbation dataset (data/docs only).
  - `drug_emb_model/hg/` — HeteroGNN drug embedding model.
  - `pert_model/xpert/` — XPert drug perturbation prediction model.
- **Repositioning workflows** — `miri_reposition/`:
  - `miri_reposition/xpert-fda-v1/` — the active MIRI screening workflow (numbered stages 01-10).
  - `miri_reposition/xpert-fda-v1_history/` — frozen pre-refactor pipeline snapshot (gitignored; parity reference).
- **Disease data** — `disease_data/miri/{GSE}/` — shared per-GSE disease inputs (raw data + DEG lists).

Components ship as libraries (code + trained weights); workflows own the scripts that generate every workflow artifact (see `docs/adr/0002`).

## Subdirectories

- [pert_data/dtoxs/](pert_data/dtoxs/CLAUDE.md) — Cardiomyocyte drug perturbation dataset (DToxS LDS-1593). 914 samples. Data/docs only, no code.
- [drug_emb_model/hg/](drug_emb_model/hg/CLAUDE.md) — Heterogeneous GNN (HeteroGNN). Contrastive learning for drug biological embeddings. Status: pretrained + fine-tuned on extended graph. Full-drug HG embeddings (11,104×256).
- [pert_model/xpert/](pert_model/xpert/CLAUDE.md) — Drug perturbation prediction model (XPert). Dual-branch Transformer, ~25M params. Status: complete (pretrain + finetune). Retains library `src/`, `pretrain/` (weights), `metadata/`, `metrics/`, `reproducing/`, PPI gene vectors. Loses `finetune/`, `drug_embeddings/`, `predict/` to the workflow.
- [miri_reposition/xpert-fda-v1/](miri_reposition/xpert-fda-v1/CLAUDE.md) — Active MIRI drug screening workflow. Numbered stages 01-10 runnable from `screen.ipynb`. Status: screening operational.
- [disease_data/miri/](disease_data/miri/CLAUDE.md) — Shared MIRI disease inputs: per-GSE raw data + DEG lists consumed by the workflow's reference building.
- [reference/](reference/CLAUDE.md) — Reference PDF archive. Background reading, no code dependency.

## Cross-Project Dependencies

- HG embeddings → `miri_reposition/xpert-fda-v1/data/embeddings/all_drugs_idx2HG.npy` (11,104×256, generated by the workflow's stage 02 via HG inference).
- UniMol 3D features → `miri_reposition/xpert-fda-v1/data/embeddings/all_drugs_unimol_arr.npy` (11,104×122×514, frozen static input).
- XPert (pert_model/xpert) → workflow: 3,127 drugs × 978 genes DEG predictions (stage 05).
- GEO → `disease_data/miri/{GSE}/` — GSE160516, GSE108940, GSE137293 raw/processed data + per-GSE DEG lists.
- Disease data → workflow stage 07 builds the integrated MIRI reference DEG list.
- Features exchanged as pre-computed .npy files — no shared runtime.
- All subprojects use conda env arc (Python 3.13), created from root `environment.yml` (see `docs/adr/0003`).
- `disease_data/miri/` R ortholog mapping uses conda env arc (R + homologene).

## Key Conventions

- Both L1000 and DTOXS data are in log2 expression space — no z-score conversion.
- Drug embeddings cover 11,104 drugs (indices 0–11103). First 8,981 used in L1000 pretraining; 8,981–11,103 are FDA-extended.
- HG embeddings: training rows (0-8980) = author reference; FDA rows = fine-tuned + quantile norm mapping (FDA/Train std=1.000).
- FDA prediction: ensemble of finetuned models, predictions predominantly down-regulated (mean deg ≈ −0.38).
- Ranking scripts must always take `--zscore` on predicted DEG (stage 06 in the workflow).
- `miri_reposition/xpert-fda-v1_history/` is gitignored (frozen provenance snapshot).

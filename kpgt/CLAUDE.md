# CLAUDE.md — kpgt/

## Overview

KPGT (Knowledge Pre-trained Graph Transformer) — 基于 LiGhT 架构的分子图Transformer。将药物 SMILES 结构式转化为高维分子图嵌入向量，作为 XPert 的药物特征输入之一。

## Environment

```bash
conda activate KPGT          # Python 3.7, PyTorch 1.10, DGL-cu113
```

**Dependencies**: numpy, rdkit, dgl-cu113, torch>=1.10, pandas, scikit-learn

## Key Workflows

### 1. SMILES → KPGT Features (most common)

```bash
conda activate KPGT
bash create_pickle.sh                 # Edit SMILES_CSV path inside first
# OR:
python src/smiles_to_kpgt_pickle.py --smiles_csv <path/to/smiles.csv>
```

Input: CSV with SMILES column
Output: `kpgt_base.npz` (molecular graph features), `molecular_descriptors.npz`, `rdkfp1-7_512.npz`

### 2. Pretrain KPGT Model

```bash
python scripts/train_kpgt.py --config base --data_path <path> --save_path <path> --n_steps <N>
```

### 3. Extract Features from Pretrained Model

```bash
python scripts/extract_features.py --config base --model_path <path.pth> --data_path <path> --dataset <name>
```

### 4. Finetune on Downstream Task

```bash
python scripts/finetune.py --config base --model_path <path.pth> --data_path <path> --dataset <name> --dataset_type <classification|regression> --metric <name> --split <name>
```

## Model Architecture

- **LiGhT** (Light Graph Transformer): 12-layer attention over molecular graphs with virtual nodes
- DGL-based `HeteroGraphConv`-style message passing
- Pretrained with path-based encoding and molecular descriptor reconstruction
- Input: molecular graph (atoms + bonds) from SMILES
- Output: 2304-dim molecular embedding

## Relationship to XPert

KPGT embeddings are consumed by XPert as one of three drug feature sources:
1. **KPGT** (molecular graph features, 2304-dim) — from this project
2. **UniMol** (3D molecular conformer features, 512-dim) — generated by `unimol_tools`
3. **HG** (biological drug embeddings, 256-dim) — from [../hg/](../hg/)

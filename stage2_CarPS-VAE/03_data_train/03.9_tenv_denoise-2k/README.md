# tenv Denoise-DEG 2k training

This plate-pooled tenv release uses the ordered 2,000-gene
[Denoise-DEG prediction axis](../../02_gene_axis/02.2_denoise-deg/README.md).
Its [manifest](output/manifest.json) pins the axis, raw counts, frozen folds
and each output. See the [tenv release contract](../03.1_tenv_hvg-5k/README.md)
for the data files and the [training builds](../README.md#tenv-training-axes)
for reproduction with `--axis denoise-2k`.

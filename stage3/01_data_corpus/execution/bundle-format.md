# Stage 3 frozen-input bundle contract
Public CLI: `python stage3/01_data_corpus/execution/corpus.py build --input BUNDLE.json --output RELEASE_DIR [--test-only]`; `... verify --release RELEASE_DIR [--test-only]`.
All production inputs frozen/offline. Bundle contains `schema_version: 1`, `sources: [...]`, `records: [...]`.
Source: `source` dataset id, `item` repo-relative pheno_data item path, `test_only` false, `assets: [{path: repo-relative source or local path, sha256: ...}]` and availability metadata. Candidate-unavailable sources may have empty assets with `status: unavailable` plus reason; must not appear as verified.
Record (one original comparison, before sample merging):
- `comparison_id` stable unique string; `source` matching registry; `condition` dictionary with all condition-prefixed attributes. Required condition_cell_type, condition_drug_time, condition_hypoxia_time, condition_reoxygen_time, condition_drug_schedule. Time hours or null (unknown); no-HR 0 is explicit.
- `phenotype`, `assay_method`, `batch` (original experiment), `drug` canonical active-parent evidence key or null, `dose` canonical mol/L float or null.
- `measurements`: list of {measurement_id, value (finite float or null), assay_method, unit, representation ('raw'/'normalized_only'/'summary'), asset (matches registered frozen path), selector, experimental_unit (string/null), normalized_value (float/null)}. Raw and normalized representations of same measurement go in one entry. Missing raw + normalized=0 stays `value:null` with normalized_value=0; no fabricated raw value.
- `identity_evidence`, `dose_evidence`, `control_evidence` strings; `quality_reasons` list of scientific exclusion strings.
- `statistics`: {treated_mean, control_mean, scale_compatible: bool, control_matched: bool, method, sidedness, p_raw, p_adjusted, correction, family_complete: bool, family_matches: bool, evidence}. Unknown fields absent/null. Numerical source p requires known two-sided method/evidence and complete family to BH. Author BH requires matching complete family. Recalculation inputs are specified below.
Records may retain unresolved identities/doses and excluded readouts. Partition is recognized even when no record admitted. Every record remains in comparisons ledger with derived FC/endpoint/exclusion reasons.
Bundle file itself hashed into release; release freezes full bundle as input.json; verifier reconstructs expected outputs using same deterministic core plus independent structural/hash checks. Source bytes verified from registry hashes, curation local additions owned source curator.
Source-specific adapter modules emit this bundle; corpus.py owns validation, statistical derivation and immutable release verification.

# Statistical input contract
`statistics.family_members`: sorted complete comparison_id list in the *same* source/complete condition/phenotype/assay/batch family; required to reuse source BH or adjust raw p. Mismatching declarations are structural failure, missing declaration leaves significance unavailable. `family_complete` and `family_matches` must both be true and source evidence must establish scope. All eligible raw p are adjusted before eligibility/magnitude filtering.
Raw source p: method+sidedness='two-sided'+evidence+batch known, `p_raw` [0,1], `correction` 'none' or 'raw'. Matching author BH: p_adjusted, correction 'BH', matching/complete flags and exact declaration. No invented p from text.
Recomputation: `independent_units:true` and `design` 'independent'/'paired' with `treated_values`, `control_values`, `treated_unit_ids`, `control_unit_ids` lists. Same unit repeated means technical observations summarized only for test; retained measurements unchanged. Paired requires identical unit key sets; independent requires disjoint IDs. At least 2 independent units each. Or `design:'independent_summary'`, `treated_summary` and `control_summary` each `{mean, sd, n}` with corrected sample SD, integer independent n>=2. Degenerate/unknown designs produce no numerical test. Recomputed means also drive FC, avoiding inconsistent duplicate summaries. Control match and compatible scale evidence still required.
All measurement extra fields retained verbatim in `source_metadata` JSON and comparisons ledger. Readout representation raw/normalized_only/summary.

# CLAUDE.md — miri_reposition/xpert-fda-v1/

## Purpose

Active MIRI drug repositioning workflow. Ranks 3,127 FDA-approved small-molecule drugs by their predicted ability to reverse the myocardial ischemia-reperfusion injury (MIRI) transcriptional disease signature. This is the refactored successor of the frozen `fda_miri_vs/` pipeline (now `miri_reposition/xpert-fda-v1_history/`). Cardiotoxicity scoring is deferred from v1.

## Stages

- 01 drug list → `data/drug_list.csv` (3,127 drugs with embedding drug_idx).
- 02 drug embeddings → arranges frozen UniMol/SMILES inputs; runs HG inference for `all_drugs_idx2HG.npy`; **idempotent** — skips when an intact table exists.
- 03 baseline transcriptome → `data/baseline/cm_ctl_landmark.csv` (workflow-owned).
- 04 finetune XPert on dtoxs → `finetune/output/dtoxs_dtoxs/`.
- 05 perturbed transcriptomes → `data/deg/xpert_fda-cm_deg.csv`. XPert predict indexes the precomputed UniMol array by drug index (finetune/predict feature consistency).
- 06 z-score → `data/deg-zs/`.
- 07 build MIRI reference → consumes `disease_data/miri/{GSE}/deg/`; writes `MIRI_up-down.json` + `MIRI_rank.json`.
- 08 efficacy scores → three scorers (WCS+RGES, Zhang/ssCMap, pathway RGES) → four z-components → integrated score.
- 09 reports → deterministic gating CSVs + gpt-researcher prompts (steps 4-6).
- 10 filter + rank → WCS<0 + ≥6/8 critical pathways → `data/ranked/ranked_drugs.csv`.

## Key Files

- scripts/scoring.py — refactored scoring logic; verified byte-identical to the frozen `xpert-fda-v1_history/scripts/` on identical inputs.
- scripts/02_drug_embeddings.py — idempotent HG embedding generation (skips if intact table exists).
- scripts/07_build_miri_deg_reference.py — regenerable cross-dataset MIRI reference.
- data/embeddings/all_drugs_unimol_arr.npy — frozen UniMol features; both finetune and predict consume this array by drug index.

## Dependencies

- Model libraries: `pert_model/xpert/` (src library, PPI gene vectors), `drug_emb_model/hg/` (HG inference).
- Disease inputs: `disease_data/miri/{GSE}/deg/` (per-GSE DEG lists).
- Environment: conda env `arc` (root `environment.yml`).
- gpt-researcher reports require API keys in root `.env` + the local embedding model under `.agents/skills/gpt-researcher/`.

## Entry Points

```bash
cd miri_reposition/xpert-fda-v1/
conda activate arc
python scripts/01_drug_list.py
python scripts/06_zscore.py
python scripts/07_build_miri_deg_reference.py
python scripts/08_efficacy_scores.py
python scripts/10_filter_rank.py
# or run all in order:
jupyter notebook screen.ipynb
```

## Notes

- Always z-score the predicted DEG (stage 06) before scoring; the scoring stage consumes the pre-z-scored input without re-normalizing.
- Reference gene sets are regenerable: stage 07 reproduces `MIRI_up-down.json`/`MIRI_rank.json` from `disease_data/`; `MIRI_pathways.json` is static.
- The frozen `xpert-fda-v1_history/` snapshot is gitignored and is the parity reference for the refactored pipeline.
- Known limitation: XPert predicts ~97.2% down-regulated DEGs with very low inter-drug variance, hurting downstream discrimination.

# Stage 3：表型方向对照与三分类证据决定

日期：2026-11-04。对应[确定表型变化方向的对照及三分类标签证据要求](https://github.com/Moke110/arc/issues/26)，
依赖[首批纳入决定](stage3-inclusion-decision.md)、[计数决定](stage3-counting-decision.md)、
[原始附表审计](stage3-sample-count-audit.md)、[活性来源核验](stage3-viability-sources.md)、
[ADR 0034](../adr/0034-stage3-phenotype-data-boundary.md)、
[ADR 0035](../adr/0035-stage3-stratified-phenotype-curation.md)及 [GLOSSARY](../../GLOSSARY.md)。
本票按用户授权由 AFK 子代理决策、主会话审阅，采用 grilling 的边界检查与 domain-modeling 的概念检查；
没有虚构用户答复，也不等待默认 HITL 确认。只决定数据与证据规则，不生成标签、不生产入库。

## 决定：先保存连续证据，方向标签合法为空

**本数据库阶段保存连续读数、可复核的效应量和来源证据；合格三分类标签是 nullable 的派生结果。**
缺匹配对照、技术有效性或不确定性时，保留事实并隔离标签，不强塞 0，不凭来源规模放宽要求。
数据库允许未知/null，Stage 3 模型的目标输出仍为 +1/0/−1；未知不是第四个训练类，
也不是 no change，不参与已标注训练目标或以 0 计分的评估分母。报告须分别列未标注数与原因。

最终数值阈值、等效界值和区间算法明确归后续模型/labeling spec，**本轮不预造一个通用百分比或 p 值门槛**。
这不是本票未决：当前默认标签为空；只有后续版本化规则与证据门槛都满足才允许产生标签。
数据库可先具有合格计数组合而没有 label-ready 数据集；≥500 合格组合的计数口径沿用前票，
不改为强制要求 500 个可靠标签，也不把数值覆盖当成二者已达标的证明。

## 对照必须回答同一个实验问题

药物效应的目标对照为：**同一生物与损伤/培养条件、同一给药/换液操作和读数时钟下，不含目标药物的匹配 vehicle 组**。
保留 study/campaign、供者/批、板、孔及配对关系，优先使用实验设计实际匹配的同板/同批对照。
汇总图只有来源组级对照时可以保留组级映射，但不能宣称已取得逐孔匹配或擅自重建配对。
跨板或跨批的参考只能在作者明确设计或后续经验证方案支持时使用，并保存理由；不以全库均值代替。

| 实验目标 | 药物方向的参考 | 另存但不替代的比较 |
| --- | --- | --- |
| 常氧直接给药 | 相同模型、培养、时长、检测及 vehicle 的常氧无药组 | 阳性毒性/保护参比是质控，不是默认分母 |
| 预处理后 HR/A-R | 同一 HR/A-R 及洗脱/持续给药/换液流程的无目标药 vehicle 组 | 常氧 vehicle 描述损伤差距；相对它的变化是另一 contrast，不能称药物对 HR 的效应 |
| 固定背景联合处理 | 完全相同背景而仅缺目标药的组才定义增量效应 | 联合干预不冒充首批单药观察；机制阳性组不能替代 HR vehicle |
| 作者归一化基准 | 保存分母对应的实际组、氧条件、vehicle、板/批、基准值及公式 | “100%”或“1”仅为尺度，不能证明分母是正确匹配对照 |

vehicle 的种类、剂量关联浓度及处理操作须匹配。Sirenko 的通常 0.1% DMSO 与 30 µM 时 0.3%
按已知 profile 保存，必须核对高剂量实际对应 vehicle；不能假设同板任意 DMSO 孔都可交换。
对照的正常跳动/存活、检测动态范围与技术质控也须可验收；无效或异常对照阻止方向标签。
不知道对照浓度、归一化分母或配对关系时，保存 unknown 及证据位置，不能因双方都 unknown 而判匹配。

## 原始值、作者归一化与效应不能互相覆盖

每个来源位置保存原始值/单位、缺失标记、作者 normalized 值/尺度及公式、文件版本和图表定位；
raw、normalized、作者均值与数字化图值是同一观察的表示，不新增组合或重复。
没有逐孔原始值时 raw 字段为空，不能把 relative viability 改称原始 RLU。

有明确对照及同尺度值时可保存带公式的连续 contrast：差值 `treated − control`；
若基准严格为正且比值有意义，可另存 ratio 或 percent change。只有正值才可直接计算 log ratio；
真实零保留，不加任意 pseudocount 伪造有限 log 值。分母为零/无效时比值为空并记录原因，
有意义的原始差值仍可保留。不能跨不同检测单位直接相减或拼接效应。
作者归一化已明确以匹配 vehicle 为 1（比值尺度）或 100% 时，可保留相对该基准的效应和描述符号，
即使 vehicle 原值未公开；但须标为 author-normalized，不能伪称独立重算或拥有对照方差。

将以下三层分开，避免“升高”一词偷换证据资格：

| 层次 | 允许内容 | 不允许的推断 |
| --- | --- | --- |
| 作者陈述 | 原文声称 increase/decrease/ns、比较对象、检验/p 值和位置 | 作者声称不是本库自动认可的三类标签；星号不补全效应或误差 |
| 描述性符号 | 在明确 contrast 上连续点估计的正/零/负号；近似图值标近似 | 不能以点值恰为基准、符号稳定或显著性星号直接获得 qualified 0/±1 |
| 合格方向标签 | 通过证据验收，按后续冻结 labeling 规则产生 +1/0/−1，连到规则版本 | 不从 control 标志、缺失、ns 或作者“无毒”称呼赋 0 |

## 证据状态与后续标签门槛

后续合同至少区分 measurement validity、control/contrast validity、uncertainty evidence、
label status/reason 与 nullable label value；多个缺口可同时存在。状态名在此是语义要求，
不规定数据库字段实现。合法标签值域仅 `null, −1, 0, +1`，null 必须附原因。

| 已有证据/状态 | 当前允许与标签处理 | 升级 label-ready 所需 |
| --- | --- | --- |
| 可追溯 raw/作者汇总，控制未知 | 保留，无法定义药物 contrast；label=null | 明确匹配对照、尺度/分母及有效性 |
| 控制与点估计明确，误差/重复不足 | 连续效应与描述符号可用；label=null | 能估计该 contrast 不确定性的重复/配对信息，或定义明确且足够的汇总误差证据 |
| 只给 p/ns、误差类型或 n 未知 | 保存原文与比较对象；label=null | 补足效应、误差类型、n/独立实验单位及对照；ns 本身永不证明等效 |
| 有 raw 或明确均值、SD/SEM/CI、n 及重复结构 | 可成为规则评估候选，尚不自动 label-ready | 技术/控制通过，版本化 labeling spec 已冻结，区间可支持明确分类 |
| 同组合重复或独立研究方向冲突 | 原测量及冲突均保留；组合标签为空 | 按预先规定的层级/冲突策略评估；不能多数投票、只挑最佳剂量或平均抹平 |
| 已确认技术失败/检出范围外无有效量化 | 保存失败/截断事实，排除该测量的连续精确效应与标签 | 有效重测或经验证的删失处理；不插补成 0 |

技术孔不当作独立培养或供者；双孔不是自动 n=2 生物重复。SEM→SD 只有 n 及实验单位明确时才可转换。
只有处理组 SD 而无对照误差/必要配对信息，通常不能重建 contrast 区间；归一化共享分母的相关性也须处理。
图中的误差条不是数字化误差；不能拿图像读取精度代替生物/测量不确定性。

**后续模型/labeling spec 的受控步骤**：先按单一读数及条件层确定有实验依据的最小有意义变化/
等效区间、效应尺度、置信区间方法、独立实验单位、多重比较与重复冲突策略，再冻结规则和版本后派生标签。
参数只能来自独立校准/训练证据，不能看测试结果调门槛。本轮不声称这些参数已校准。
若采用区间规则，+1/−1 必须有足够证据超出相应有意义变化边界；0 必须有正面等效证据
支持效应落在预先界定的 no-change 区间内，而不是“区间跨0”或“p≥0.05”。
跨边界、精度不足、缺必要方差或规则未定义时一律 null；即使标签不全也不能为凑三类放宽。

## 零、停搏、非显著与图值的具体处理

数值 0 是测量事实之一，与方向类 0 无同一性。真实 beat count=0 且匹配正常跳动对照有效，
可有负的描述性变化；需质控确认真实停搏及不确定性规则支持，才可能给 −1。
无峰时峰宽/衰减等参数的算法回退零不是“峰形减小”：保留 undefined/no-peak，不能作为精确零效应。
零信号可能是检出限/背景扣除/技术失败；未明确时记录 zero-unresolved，隔离标签和依赖有效测量的计数资格。
阴性结果/未达显著、作者“无细胞毒性”、处理=100%或四舍五入恰相等均不等于 no change。

图值仅在坐标、尺度、剂量、组别、对照和误差条可辨认时提取；保存原图位置、软件/方法、
线性或对数轴、误差类型、n/重复结构及独立复核。保留合理有效位数和提取区间，
不把像素坐标写成高精度真值。提取误差使符号或分类越界时保持 null。
即使作者给显著性星号，关键图值/误差/对照不可读时也停止该观察的标签升级。

## 首批来源的验收案例

以下为规则案例，不是已执行标签或最终可用数量；来源事实沿用[原始审计](stage3-sample-count-audit.md)
及[活性来源核验](stage3-viability-sources.md)，原始链接见各文档。

| 案例 | 本轮决定 | 解除隔离的具体证据 |
| --- | --- | --- |
| Sirenko 24 h beat count，非缺失 normalized 值 | 正文确认按板 DMSO 归一化；先保留 author-normalized 数值，只有尺度/基准/映射证据明确后才计算相对基准效应和描述符号，不能凭表值近100的外观赋符号；没有 vehicle 原值/SD，label=null | 核对 normalization 公式、剂量 vehicle 匹配和技术有效性；获得足以评估 contrast 的重复/控制误差，且冻结 labeling 规则 |
| Sirenko Ascorbic acid/Biotin 0.3 µM r1 raw 空白、normalized=0 | 同时保存两者；normalized=0 是来源表示，不是该重复观测到停搏；该重复无可用测量/标签 | 可核实原始值/勘误才能修复；r2 若有效可独立保留但不补造 r1 |
| Sirenko 两份 raw=0；Control=1 | 双零不自动失败也不自动 no change；Control=1 是化合物分类标志，不是 vehicle 或 0 标签 | 前者需区分真实停搏/检测失败并评估有效对照；后者始终按化合物观察独立审核 |
| Heliste S1 HYP/CTRL relative viability | 分母氧条件未知，无法直接算药物相对 HR vehicle 的方向；不得以 HYP/CTRL 自造保护比值。保留全部剂量，label=null | 明确各列归一化分母和公式、氧条件匹配、重复/误差；时长及持续用药缺口另须独立解决，补分母不自动解除纳入隔离 |
| A/Linn Fig.3，hiPSC-CM 与 AC16，单药48 h MTT | 两模型分开；作者非给药=100%可保留，但 vehicle/剂量网格与误差/重复结构待核，不凭曲线接近100赋0 | 逐图核对真实匹配 vehicle、剂量、SD/SEM及其n，独立复核提取，按后续规则验收；CC50不是逐剂量方向标签 |
| B/Liu icariin 常氧24 h及预处理后HR CCK8 | 常氧比常氧 vehicle，HR比HR vehicle；不能统一比常氧100%；单药与erastin/Znpp机制组合分开 | 逐图明确PBS/vehicle及误差、重复单位与处理时序；无法确认的机制图保持隔离 |
| D/Duan SYA/NAC，Fig.2B 24 h预处理后A/R MTT | 单药各剂量对照A/R模型组；正常组用于损伤背景，不替代药物contrast；4 h常氧图仍排除 | 明确模型组vehicle和操作、误差类型/n、可靠图值；不能从“保护”文字直接赋+1 |
| 图柱近100%、标ns，或误差条不可分辨 | 可保存作者陈述/近似值及失败理由，label=null | 有可复核效应与不确定性且正面支持等效才可能赋0；补一枚星号不足 |

MTT 与 CCK8 为不同检测端点，CTG 为独立 ATP 相关读数，beat count 又是功能指标；
均按各自 readout_key/层保存。没有经验证映射时不能合并为一个“viability”训练标签或混算500，
也不能把相同百分比视为相同生物效应。方向只描述该读数相对指定对照的升降；
beat count 增高可能涉及异常节律，MTT/CCK8/CTG信号增高也不自动等于细胞数增加或 MIRI 获益。
效益解释需要独立目标和证据，本票不生成疗效好坏标签。

## Resolution 与交接

本票已选择匹配 vehicle/损伤上下文、原值与作者归一化并存、描述符号与合格标签分离、
unknown/null 合法及 evidence-first 的保守门槛。缺口不会触发继续追问用户或无限追查：
现有证据不足即记录原因、保持隔离，后续取得可核实证据才升级；联系作者仍需另行授权。
最终数值阈值与算法交给后续受控模型/labeling spec，并以冻结规则为生成任何三分类标签的前置条件。
因此本票没有留下一个需要本轮再作的人类选择；也未宣称 Sirenko 或任何来源已经 label-ready。
后续整理分别报告来源保留、合格组合、contrast可计算、uncertainty充分、label-ready及最终各类/null数量，
每步附排除原因与证据索引，不以强制补0掩盖证据损耗。

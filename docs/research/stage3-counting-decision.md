# Stage 3：药物身份、条件等价与非重复组合计数决定

日期：2026-11-04。对应[定义独立药物表型样本与跨研究条件等价及去重规则](https://github.com/Moke110/arc/issues/25)，依赖

[ADR 0034](../adr/0034-stage3-phenotype-data-boundary.md)、
[ADR 0035](../adr/0035-stage3-stratified-phenotype-curation.md)及 [GLOSSARY](../../GLOSSARY.md)。
本票使用 grilling 的边界检查与 domain-modeling 的概念检查；用户已授权 AFK 决策、主会话审阅，
下文为代理取舍，没有虚构用户问答。只决定后续可执行规则，未做实际化学映射、生产入库或标签生成。

## 决定与计数单位

**第三类 ≥500 按一个可比较实验层中，合格且非重复的药物×精确条件×单指标组合验收。**
一个药物四剂量可以贡献四组合，但仍是一种药物；这些组合不是统计学独立药物或独立生物重复。
研究篇数、供者、批次、板和孔数都不是扩大 500 的因子。同条件同药跨研究独立复现实验只增加证据，
新研究中新增的合格药物或不同合格剂量/时间才可能增加组合。跨研究合并必须先通过逐字段条件等价验收。

分开报告以下量，禁止把其中一项改称另一项：

| 量 | 定义 |
| --- | --- |
| 原始来源记录数 | 按文件版本、表/图位置、原始身份、剂量、读数和作者重复标识定位；同一重复的 raw 与 normalized 是两个表示，不是两份生物观察 |
| 来源内有值组合数 | 原始名称/标签×作者剂量×作者时间×单指标，至少一份有限测量；这是审计覆盖口径，不宣称身份合格 |
| 合格独立药物数 | 指定层内通过药物资格和身份验收的不同 `drug_key` 数；有多少剂量都只计一次 |
| 合格非重复组合数 | 指定层内不同 `(drug_key, condition_key, readout_key)` 数；重复证据关联到同一组合 |
| 重复与不确定项 | 分别列技术重复、生物重复、独立研究复现、重复出版、汇总值及重复类型未知的数量；未知不算独立重复 |

每项保存资格状态和理由：`qualified`、`excluded`、`unresolved`。资格未知不贡献合格分子；
不能把尚未完成映射的来源内有值组合当成已验收组合。计数资格也不等于方向标签可用。

## 药物身份：保留制剂，按有证据的活性母体计药物

保留原始名称、CAS、厂商、catalog、批号、原始结构和出处，不能覆盖成一个清洗名称。
使用两个不同身份：

- `formulation_key`：实际给药的精确化学形式，包括盐/水合物、立体化学、组分及比例；
  无法确定时使用来源局部身份并标记未解析，不虚构结构键。
- `drug_key`：有证据解析的单一活性母体，保留已知立体化学。去掉明确的非活性对离子/结晶水
  可以归同一母体；不能去掉共价基团，把前药、代谢物或不同活性成分认作母体的别名。
  稳定内部键连接经审计的结构/注册标识与映射版本，不能只以规范名称或 CAS 字符串充当化学唯一键。

执行顺序是药物用途资格→实际给药身份→母体映射→剂量基准→条件等价→去重计数。
治疗药物、明确开发候选和符合上游政策的药用天然产物可以进入主清单；技术参比、环境毒物和
用途未知者依旧排除或隔离。CAS 存在、作者称其为 drug、数值非零都不授予药物资格。

| 身份边界 | 明确规则 |
| --- | --- |
| 拼写、大小写、空白、品牌及历史别名 | 字符串规范化只生成待核对候选；通过原始产品/结构或可追溯注册记录确认同一给药物后才归并。名称相同不自动合并，名称不同不自动分开 |
| CAS 缺失、catalog 为 N/A | 不单独构成排除；其他证据能唯一解析实际形式及母体时可合格。catalog 仅在厂商与版本范围内有意义 |
| CAS 与名称/结构冲突 | 保留全部冲突与证据位置，暂停该条身份资格；不按多数票或随便优先 CAS 消歧。以原始产品或作者明确勘误等可核实证据解除 |
| 盐、游离酸/碱、水合物 | 母体药物数不增加。只有明确组分、浓度计量基准可换算为活性母体摩尔浓度，且制剂/溶解与测量可比性有证据时才在同一层合并；否则留在制剂隔离层，不能因盐种不同在同层多算 |
| 对映体、非对映体、外消旋物 | 已知不同立体组成保留不同 `drug_key`；外消旋物不等于任一纯异构体。立体组成未知不推断为纯异构体或外消旋，也不据此创建额外合格药物 |
| 化学结构唯一标识缺失 | 不要求必须有一个特定格式的 InChIKey；可追溯的产品/注册证据若足以唯一解析也可建立内部键。仅有模糊名称时只能来源局部键，不计合格500 |
| 混合物、复方、联合机制干预 | 记录各组分、比例、剂量和顺序；不拆成多个单药观察，不贡献本轮单药500。已知外消旋药物作为确定立体组成的单一药物保留；成分不定提取物隔离 |

母体映射不等于证明盐型之间生物等价。不能把精确制剂作为 condition 的任意附加标签，
让同母体同剂量的许多产品无上限增加组合；无法合并的制剂层各自报告，不能相加过门槛。
未知身份之间既不默认相等，也不默认不同；保留候选链接而不贡献合格唯一数。

## 三种键与条件等价

键是后续整理的数据约定，本文不规定数据库实现。所有规范值都必须能回溯原始值和转换依据。

**`stratum_key` 固定一个可比较目标。** 组成字段为：

1. 纳入类别与单一 `readout_key`：实际测量量、检测技术/试剂体系、读出单位/窗口及可证明的转换；
   beat count 未知采样窗口不能转换为 bpm；MTT、CCK8、CTG、Calcein 计数及不同峰形参数互不替代。
2. 生物模型：物种、原代/iPSC/永生化类型、明确细胞系或产品及分化/成熟方案、已知心房/心室来源、
   正常/疾病/基因改造背景与培养体系。不同供者ID不是新层，但不同疾病/基因背景是。
3. 实验方案：直接给药或预处理→HR，氧条件和损伤诱因，HR各段时长及氧水平，药物加入顺序、
   洗脱/持续/补药策略、固定背景处理与读数相对HR的时点。
4. 测量参照：vehicle的种类、匹配原则及浓度随剂量变化的已声明profile、比较对象的生物条件、归一化的分母语义及方法。
   原始与归一化值若可追溯到同一观察可以共存；分母未知不与已知分母跨源合并。
5. 允许变化的剂量/时间轴：直接暴露名义24–48 h，或明确24–48 h预处理后HR；
   剂量、确切时间不是层ID中的固定值，而是下述精确条件字段。制剂可比性未证实时另层隔离。

**`condition_key` 在层内记录真实实验自变量。** 包含活性母体摩尔浓度与给药日程、
精确给药/预处理/读数时间，dose-linked vehicle浓度，以及该方案中有生物意义的其他变化。
同层同药不同剂量、24 h与48 h可以各算一个组合；任意时间分箱、四舍五入、单位表示差异或
重复测量次数不能创建新组合。相同数量的单位精确转换视为同剂量；质量浓度换摩尔浓度须确认
实际形式、分子量和计量基准。只知浓度范围、不能辨明重复剂量的记录不计精确组合。

vehicle-profile属于固定的stratum字段，condition仍记录每个观察实际使用的vehicle浓度。
Sirenko中0.1%与30 µM对应0.3% DMSO构成已声明的剂量关联profile；同一按板匹配vehicle的剂量系列
可留在一个层，但必须明确这不是纯粹药物剂量效应。相同药物、剂量、时间而仅vehicle浓度不同，
属于不同profile，必须隔离到不同stratum，各层独立验收，不能在同层增算组合或任意视为重复测量。
跨研究也必须证明vehicle-profile等价，不能仅因溶剂同为DMSO就归并。

**`replicate_key` 与来源键保存实验谱系。** 研究/实验campaign、文件版本、供者、分化批、培养批、板、
孔、重复号、原始/汇总层级都保留；这些字段不进入增加500的组合身份。
同一供者不同孔为技术或实验重复的具体类型由作者设计决定；不同供者/独立培养可为生物重复，
但均不创造同药同条件的新组合。供者差异无法归属于同一模型/背景时隔离，不以缺失ID充当新药物。

**跨源等价采取“证明后归并”，不能以同研究ID替代条件，也不能以不同研究ID制造新条件。**
逐字段记录源值→规范值→证据→等价结论；上列固定字段必须相同或有明确、可复核的等价论证。
普通单位换算不需要额外生物论证；不同细胞产品、成熟方案、试剂、HR程序、control语义不能
靠“都是心肌”“都24 h”或批次矫正宣称相同。不设通用时间/剂量误差容限。

固定字段缺失时可保留来源内部明确一致的实验系列及原始计数，但不能用“unknown==unknown”
宣称跨源等价。缺失影响纳入资格的关键字段（模型、时序、持续用药等）时隔离合格计数；
仅供者ID、板号等谱系字段缺失不自动否定观察，也不允许推断生物重复数。
无法证明等价的来源各层独立列数，不相加验收500。已证明等价则取组合集合的并集，重叠部分只计一次。

## 时间字段保留作者表述与实验时钟

至少分别记录作者名义时点、首次给药时点、检测开始、试剂孵育、读出时点、HR开始/结束、
洗脱/换液/补药事件、实际已知暴露区间、总实验历时及每项的出处/推导公式/未知状态。
只在已知持续用药时计算总药物暴露；总历时不等于暴露时长。

- Sirenko作者标“24 h”，Methods为给药23.5 h后加试剂，再30 min读数：保留全部时钟，
  按上游选择纳入名义24 h层；不能删去23.5 h，不能宣称已证实24 h全程无检测干预。
  其他研究的纯24 h培养后检测不据名称自动等价，要核对检测时序。
- Heliste记录24 h预处理→48 h缺氧→24 h复氧、约96 h总历时；HR期间持续用药未知。
  不算已知24 h总暴露，也不进入已知持续/洗脱层。即使未来明确持续，仍属于对应HR层，
  不能与常氧24 h或洗脱24 h混算；平行常氧约96 h仍不符合直接24–48 h目标。

## 重复出版与重复证据

优先以原始实验campaign/样本标识、文件哈希与作者来源声明链接同一实验；同数值向量或相同药名
只能提示复核，不能单独证明重复实验。原文、附表、后续综述、数据库镜像及同实验再分析连到一个
源观察；保留全部出处但不增组合。勘误/新版建立替代关系，验收只用获确认版本，旧版留谱系。
怀疑重复但无法核实的候选标疑似重叠，不以其额外来源记录推动500；相同组合无论如何只计一次。

独立研究同组合有不同结果时保留各测量、重复类型和冲突标记，不平均抹平，不挑有利研究。
组合身份仍唯一；已确认技术失败的值排除，若尚有有效证据组合可保留。对方向与误差的处理留给后续票。
作者只给均值/图柱时是一条汇总观察，n=6不能展开成6条；不知道n也不默认n=1的生物重复。

| 标签写同一药但CAS与结构冲突；或仅名称疑似别名 | 两者保持来源身份和冲突/候选映射，未知部分不增加合格药物或组合；不猜测不同也不猜测相同 |
| 同一实验附表、数据库镜像、后来论文重用，另有原图与均值 | 链接同一实验；raw/normalized/均值与图是同一观察的表示，不能多计 |
| 七个Sirenko sheet、CTG与MTT、或Heliste HR与常氧 | 各单指标/方案层独立列数，禁止加总为一个≥500指标 |

## 后续计数报告与本票 resolution

后续实现必须给出逐层资格漏斗：来源标签/有值组合→用途合格→身份解析→条件与测量有效→
跨源等价及去重后的药物数/组合数；每步列排除、未知及其原因，提供组合到来源位置的可复核索引。
另报技术/生物/研究重复和重复出版，不让重复数进入组合分子。记录身份映射与等价规则版本；
不实际完成这些验收前，不输出一个猜测的“最终有效药物数”。

现状保持：Sirenko 24 h beat count原始覆盖524组合、514双raw齐全；Heliste每氧条件2,756有限值。
这些是[实测审计](stage3-sample-count-audit.md)结果，并非合格500证明。
Sirenko若身份/用途/有效性整理后不足500，按上游政策报告该来源单独未达标；只有同指标且条件等价
已证明的新增唯一组合可以补充。Heliste不得用大表规模绕过未知用药状态或归一化问题。

本票 resolution：**确定双层药物身份、实验层/精确条件/重复谱系三种键及跨源集合并集去重规则；
500计非重复合格组合，研究、供者、批次、孔、盐型别名和重复出版不制造增量。
多剂量/合格时间可贡献组合，仍须分报药物数。规则已决定，实际chemical mapping与合格500验收未执行；
本票不设计训练切分，不生成方向标签，也不批准生产入库。**

**Status** Accepted design, 2026-11-26.

Name the project CarPS (Cardiomyocyte Perturbation Prediction System) and give its cardiomyocyte chemical perturbation prediction stage the canonical directory `stage2_CarPS-VAE/`. The live tree moves as one materialized unit. The archive keeps its internal paths and manifest, external weight links keep their targets, and exact replay of the Step 06.4 sealed registrations uses the original code revision and path layout. See [ADR 0087](0087-stage2-active-steps-and-history.md) for the archive boundary.

Select `XΔ-XΔ` from [Step 06.4](0098-transigen-shape-round4.md) as CarPS-VAE. The shared signed Δ decoder reconstructs measured Δ and predicts Δ. Across nine matched fold and seed coordinates, the shared arm had the lowest mean Δ RMSE (0.240752) and mean Δ PCC of 0.428830. Its differences from the independent decoder were small relative to the dispersion of the pairs. Retain the selected Denoise-DEG 5k axis, measured same-plate DMSO, native Gaussian prediction head, and training-fold dose transform. The objective uses control MSE, measured Δ reconstruction MSE, predicted Δ MSE and 1.75 times predicted Δ L1, plus 0.1 times the sum of both measured Gaussian prior KLs and the prediction-to-measured-Δ KL.

Step `07_cpsv_alpha` owns the initial model release, its public execution entry point, the selected KPGT configuration, and the evidence linking it to Step 06.4. Accept the release only after verifying checkpoint loading and prediction parity with the selected arm. Preserve the accepted Step 07 implementation, default configuration, and release identity for later replay. Later experiments own their variants and results and call the fixed Step 07 interface. Define the chemical input boundary at release time so Step 08 can supply a native-width chemical input and first projection while sharing the rest of the model. KPGT continues to follow its original initialization path.

Step `08_cpsv_chem-emb` compares ECFP4C, ECFP6C, FCFP4C, FCFP6C, E3FP, KPGT, and UniMol on the frozen tenv Denoise-DEG 5k release. Inherit the 06.4 protocol and use cold-drug folds 0–2 with training seeds 17, 42 and 2026. The seven accepted vector matrices cover all 459 parents in the 1,383-condition corpus. Use the native feature width and a 400-wide first projection output for each arm. Pair downstream initialization and the random stream across arms. Include all 63 fold and seed coordinates. Reuse the nine accepted KPGT fits only when the original provenance, input and model equivalence, and replay evidence pass. Fit and replay any reference coordinate that fails the reuse gate.

Publish the nine inherited metrics with fold and seed values. Prioritize same-fold, same-seed Δ PCC and Δ RMSE differences relative to KPGT, with foldwise summaries and overall mean and sample SD. Keep KPGT as the working default if the metrics disagree or differences are small relative to repeat variability. Any later adoption is a separate configuration tied to the comparison evidence. The alpha release remains the fixed reference.

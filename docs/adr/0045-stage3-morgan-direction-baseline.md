# Establish a Morgan baseline for Stage 3 phenotype direction prediction

**Status: accepted scope; remaining design decisions under discussion (2026-11-06)**

Stage 3 ultimately maps a drug-induced transcriptomic perturbation Δ to cardiomyocyte phenotype direction. While Stage 2 transcriptome prediction is unfinished, `stage3/02_base_morgan` will establish a Morgan-fingerprint baseline. The user accepted a shallow MLP with one nonlinear hidden layer; Morgan and future Δ predictors share the hidden-layer and output-head architecture, with the first layer accommodating their different input dimensions.

The target is decrease, within-band, or increase in the phenotype readout relative to its declared control, rather than a therapeutic-benefit label. The initial phenotype is `cell_viability`, using the magnitude directions established by ADR 0044. Train a separate model for each `(condition, phenotype)` pair. Each model outputs only the probabilities of -1, 0 and +1 through one three-class Softmax; these probabilities sum to one. There is no shared multi-phenotype output model. The Morgan baseline takes both the fingerprint and dose as inputs; the dose encoding remains to be settled.

The baseline is designed to support a later comparison of structural information with predicted transcriptomic Δ. Freeze shared sample-splitting, labeling and evaluation protocols during baseline design; a paired comparison on jointly covered samples will be needed if future Δ coverage is incomplete. This avoids making model comparisons depend on different evaluation populations. Evaluate three generalization settings: unseen drugs, unseen doses, and warm start. Exact split definitions, dose encoding, optimization and numerical evaluation metrics are not yet settled. The earlier recommendation of a single cold-drug evaluation is expanded to these three settings; no cross-setting split policy has yet been accepted.

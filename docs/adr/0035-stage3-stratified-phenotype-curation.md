# Stage 3 curates experimental strata before training labels

**Status: accepted (2026-11-04)**

The user delegated completion of the remaining wayfinder decisions to sequential
subagents with main-session review. That delegation replaces the default HITL and
one-ticket-per-session procedure; it does not relax the scientific scope in ADR 0034.

Stage 3 first curates the exact MTT/CCK8 literature as small figure-level pilots
and prioritizes Sirenko's 24 h iPSC-CM beat count as the third-category source and
single-readout feasibility target. Heliste's larger CTG screen remains an isolated
HR extension while drug persistence and normalization are unclear. A larger table
does not justify treating unknown exposure as a known 24–48 h condition.

Source retention, qualified counting, and direction-label readiness are distinct.
Species/cell models, readouts, injury protocols and drug persistence remain separate;
explicit continuous dosing during HR is allowed as its own protocol stratum, while
unknown persistence does not contribute to a known-protocol 500-observation claim.
Nontherapeutic reference compounds can be retained without contributing qualified
drug counts. If qualification reduces the preferred source below 500, report failure
of that gate and keep the source exploratory instead of silently redefining drugs,
combining endpoints, or lowering the threshold. This trades apparent dataset size
for a reproducible experimental target.

[inclusion decision](../research/stage3-inclusion-decision.md) and its owning
[decision ticket](https://github.com/Moke110/arc/issues/24).

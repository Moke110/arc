# Learning Record 0001: HG/XPert training pipeline mapped

The user's mental model of the two-model training pipeline was established in flowchart form: HG pretrain (L1000, 8,981 drugs, InfoNCE contrastive on PPI/DTI/DDS) → HG FDA finetune (extended graph, 11,104 drugs, low-LR 5e-5, cosim≥0.95 guard) → all-drug table `all_drugs_idx2HG.npy`; and XPert pretrain (L1000 336k samples, loss `0.2·L_trt+0.003·L_ctl+0.2·L_deg+1.0·L_pcc`) → XPert finetune on DToxS. The key contrast is orchestration: v0 ran training ad-hoc from inside the model libraries (`pert_model/xpert/finetune/run.sh`, `predict.sh`), while v1 is the 11-step workflow (`stage1/xpert-fda-miri-v1/`) where the workflow owns artifacts and the libraries stay pure.

Why it matters: any future session on modifying/reproducing either model can assume this map and go straight to the v0↔v1 orchestration differences, hyperparameter tuning, or parity checks rather than re-deriving the pipeline layout. It sets the ZPD floor for the next lesson.

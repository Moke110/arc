# Virtual-cell drug-perturbation model survey — 2026-10-19

Scope: find additional **open-code** models that map a chemical perturbation
(SMILES/structure, optionally dose) to a transcriptome, beyond the four Stage 2
entrants (`chemCPA`, `CPA`, `biolord`, `PRnet`) and the already-vendored
`State`, `XPert`, and `TranSiGen`.

Sources: the 162 full-text markdowns in `reference/markdowns/`, the
`biomni` literature/repository survey (full report at
`../.scratch/virtual-cell-drug-perturbation-survey.md`), GitHub repository
metadata, and direct inspection of the cloned code and checkpoints.

## Gates used

| gate | requirement |
|---|---|
| **G1** | whole-transcriptome output, ideally usable at ~20k genes (not only 978 L1000 landmarks) |
| **G2** | cold-drug generalisation from chemical structure (SMILES/graph/fingerprint through a fixed encoder), not an `nn.Embedding(n_drugs)` |
| **G3** | dose is an input or covariate |
| **G4** | public code, trainable on one 16 GB GPU in ≲16 h |

## Headline finding

**No published chemical model reaches ~20k genes while also supporting a cold
drug and dose.** The practical options are:

1. **978-landmark drug models** (WAVE, ExPO, DeepICER, MiTCP, LDM-Drug) — mature
   cold-drug/dose formulations, but need an expansion/imputation step for
   whole-transcriptome use.
2. **Configurable single-cell models** (PerturbNet, Squidiff, CMonge) — can emit
   the measured HVG space (5k–17k) and support unseen drugs, but must be
   retrained on the target dataset and do not magically produce 20,570 genes.
3. **Genetic models** (GPO-VAE, Stable-Shift, AROMA) — prove that 8k–17k-gene
   decoders are feasible, but have no chemical encoder.

For the Stage 2 decision this means the gene-space/retraining strategy is still
the real constraint; adding a model does not remove it.

## Recommendations

- **PerturbNet** is the strongest new entrant: distributional output, explicit
  dose/cell-type covariates, a real SMILES encoder, and a 5,087-gene sci-Plex
  checkpoint that loads cleanly. Its main costs are GPL-3.0 and a Python 3.7 /
  TF 1.15 (or 3.10 beta) environment.
- **CMonge** is the cheapest honest cold-drug/ dose baseline: MIT, ~23k
  parameters, minutes to train, RDKit structure conditioning. Use it as a sanity
  floor for any heavier model.
- **Squidiff** is the only candidate whose gene dimension is truly open-ended;
  its cold-drug path is an optional rFCFP + dose scaling, so treat it as a
  candidate architecture rather than a ready drug model.
- **WAVE** and **ExPO** should be used as 978-landmark baselines and as sources
  of evaluation protocol (ExPO's Bemis–Murcko scaffold split is the strictest
  cold-drug split in this literature).
- **DECANT** is the right representation-learning idea but is not runnable
  without reconstructing its processed cell-bag data.

## Not pursued

- **DeepICER** and **MiTCP** have public code but no licence file, so they are
  legally “all rights reserved”; they are recorded here for reference, not
  vendored.
- **scDPR**, **X-Pert**, and **PertFlow** could not be verified as runnable
  public code at survey time.
- All per-drug-embedding models (CellCap, scVIDR, scPerb, scPILOT, W1OT,
  MultiPert) fail cold-drug generalisation by construction: the perturbation is
  a categorical index or a learned embedding, not a chemical encoder.
